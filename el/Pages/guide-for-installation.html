Οδηγός Εγκατάστασης

Βήμα προς βήμα οδηγίες για την εγκατάσταση και τη ρύθμιση του DedSec Project σε Termux για Android, Ubuntu, Kali Linux ή Linux Mint.

Απαιτήσεις

  • Υποστηριζόμενο σύστημα: Termux σε Android, Ubuntu, Kali Linux ή Linux Mint.
  • Αποθηκευτικός Χώρος: Ελάχιστο 6GB ελεύθερος χώρος για την εγκατάσταση του DedSec Project.
  • RAM: Ελάχιστο 2GB.

Προειδοποίηση αποθηκευτικού χώρου: Η απαίτηση των 6GB αφορά την ίδια την εγκατάσταση του DedSec Project. Scripts που καταγράφουν ή αποθηκεύουν επιπλέον περιεχόμενο—όπως φωτογραφίες, screenshots, βίντεο, ηχογραφήσεις, logs, λήψεις ή άλλα αρχεία που δημιουργούνται—μπορούν να χρειαστούν επιπλέον χώρο πέρα από την απαίτηση των 6GB του project.

Χρόνος εγκατάστασης: Η πλήρης εγκατάσταση μπορεί να διαρκέσει περίπου 20–50 λεπτά, ανάλογα με τη σύνδεσή σας στο internet και τον επεξεργαστή της συσκευής σας.

Βήματα Εγκατάστασης

Υποστηριζόμενες πλατφόρμες: Termux σε Android, Ubuntu, Kali Linux και Linux Mint. Αν χρησιμοποιείς Android, ακολούθησε την προετοιμασία για Termux παρακάτω· οι χρήστες desktop Linux μπορούν να παραλείψουν τα βήματα Android/F-Droid και να χρησιμοποιήσουν την εντολή Linux στο Βήμα 2.

1. Termux Σε Android: Εγκατάσταση Termux & Πρόσθετων

Σημείωση: Για την εγκατάσταση APKs (π.χ. F-Droid), βεβαιωθείτε ότι έχετε ενεργοποιήσει άγνωστες πηγές στις Ρυθμίσεις > Ασφάλεια > Εγκατάσταση άγνωστων εφαρμογών.

Εγκατάσταση F-Droid

Το F-Droid είναι ένα εναλλακτικό κατάστημα εφαρμογών για Android που παρέχει ελεύθερο και ανοιχτού κώδικα λογισμικό. Είναι ο συνιστώμενος τρόπος για να εγκαταστήσετε το Termux και άλλα εργαλεία ασφαλείας.

Λήψη F-Droid

Πώς Να Εγκαταστήσετε Αρχεία APK Στο Android:

  1. Κατεβάστε το APK του F-Droid από τον παραπάνω σύνδεσμο.
  2. Ανοίξτε τις Ρυθμίσεις της συσκευής σας > Ασφάλεια (ή Εφαρμογές & Ειδοποιήσεις).
  3. Ενεργοποιήστε την 'Εγκατάσταση από άγνωστες πηγές' για το πρόγραμμα πλοήγησης ή τον διαχειριστή αρχείων.
  4. Ανοίξτε το κατεβασμένο αρχείο APK και πατήστε 'Εγκατάσταση'.
  5. Μόλις εγκατασταθεί, ανοίξτε το F-Droid και αναζητήστε 'Termux' για να το εγκαταστήσετε.

Εγκατάσταση Πρόσθετων Termux

Για πλήρη λειτουργικότητα, συνιστούμε την εγκατάσταση των παρακάτω πρόσθετων Termux από το F-Droid:

Termux (Προσομοιωτής Τερματικού) Termux:API Termux:Styling

Συμβουλές Για Το Termux

Διατήρηση Οθόνης Ανοιχτής

Για να αποτρέψετε την απενεργοποίηση της οθόνης κατά τη διάρκεια μεγάλων εργασιών: κρατήστε πατημένη την οθόνη του Termux, μετά πατήστε 'Περισσότερα' και επιλέξτε 'Διατήρηση οθόνης ανοιχτής'.

Αλλαγή Στυλ Τερματικού

Μπορείτε να προσαρμόσετε την εμφάνιση του τερματικού: κρατήστε πατημένη την οθόνη του Termux, πατήστε 'Περισσότερα' και επιλέξτε 'Στυλ' για να αλλάξετε χρώματα και θέματα.

Προετοιμασία Desktop Linux

Τα Ubuntu, Kali Linux και Linux Mint δεν χρειάζονται F-Droid ή πρόσθετα Termux. Άνοιξε το κανονικό terminal του συστήματός σου και συνέχισε με το Βήμα 2 παρακάτω.

2. Ενημέρωση Πακέτων & Εγκατάσταση Git

Termux (Android)

Σημαντικό: Ανοίξτε την εφαρμογή Termux στη συσκευή σας πριν αντιγράψετε και επικολλήσετε την παρακάτω εντολή.

pkg update -y && pkg upgrade -y && pkg install git nano -y && termux-setup-storage

Ubuntu / Kali Linux / Linux Mint

Τρέξε το παρακάτω στο κανονικό Linux terminal. Το setup του project θα δημιουργήσει και θα χρησιμοποιήσει τοπικό .venv, ώστε να μην αντικαθιστά το Python environment που διαχειρίζεται η διανομή.

sudo apt update && sudo apt install -y git python3 python3-venv python3-pip

Θέλεις Να Ελέγξεις Το DedSec Πριν Το Εγκαταστήσεις;

Δες τον πηγαίο κώδικα, το README, τις ενημερώσεις και τη δραστηριότητα της κοινότητας απευθείας στο GitHub.

Άνοιξε το DedSec στο GitHub

3. Κλωνοποιήστε Το Αποθετήριο

git clone https://github.com/dedsec1121fk/DedSec

4. Εκτελέστε Το Script Εγκατάστασης

cd DedSec && bash Setup.sh

Το Setup.sh εντοπίζει αυτόματα την πλατφόρμα. Το Termux χρησιμοποιεί τον native installer του Termux, ενώ Ubuntu, Kali Linux και Linux Mint χρησιμοποιούν apt dependencies μαζί με το τοπικό .venv του project. Μετά το setup, μπορείς να ανοίγεις το project με ./Run.sh σε κάθε υποστηριζόμενο σύστημα.

Το script θα αναλάβει την πλήρη εγκατάσταση. Στο Termux, μετά την εγκατάσταση, πρέπει να αλλάξετε το prompt, να αλλάξετε το στυλ του μενού (τα στυλ λίστας ή αριθμημένου μενού είναι τα καλύτερα για νέους χρήστες), να επιλέξετε γλώσσα και να τρέξετε την επιλογή Save DedSec Project στο πρώτο σας άνοιγμα ώστε να δημιουργηθεί αμέσως το backup package. Το Save DedSec Project μπορεί να πάρει λίγη ώρα ανάλογα με τη σύνδεσή σας στο internet και το terminal μπορεί να μένει κενό μέχρι να ολοκληρωθεί. Τρέχετε ξανά το Save DedSec Project λίγες φορές κάθε χρόνο ώστε το αποθηκευμένο πακέτο του DedSec Project να μένει φρέσκο και έτοιμο αν το χρειαστείτε. Μετά από αυτό, κλείστε το Termux από το πάνελ ειδοποιήσεων του κινητού σας χρησιμοποιώντας το κουμπί εξόδου και έπειτα ανοίξτε ξανά το Termux. Συμβουλή: Μπορείτε να ανοίξετε γρήγορα το μενού πληκτρολογώντας 'e' (Αγγλικά) ή 'g' (Ελληνικά) στο Termux.
