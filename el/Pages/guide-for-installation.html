Οδηγός Εγκατάστασης

Εγκατέστησε το ίδιο DedSec Project σε Termux για Android, Ubuntu, Kali Linux ή Linux Mint με το κοινό cross-platform setup και launcher.

Υποστηριζόμενα Συστήματα

Termux σε Android

Χρησιμοποιεί native Python και πακέτα Termux. Η πρόσβαση σε Android storage και οι λειτουργίες Termux:API παραμένουν διαθέσιμες όταν υπάρχουν τα απαραίτητα permissions και add-ons.

Ubuntu

Χρησιμοποιεί πακέτα apt και τοπικό .venv. Ο launcher προσθέτει το Compat/bin ώστε τα portable εργαλεία του DedSec να χρησιμοποιούν το desktop compatibility layer.

Kali Linux

Χρησιμοποιεί το ίδιο desktop setup με υποστήριξη Bash ή Zsh, τοπικό .venv και Linux-aware paths για Downloads.

Linux Mint

Χρησιμοποιεί το ίδιο Ubuntu-family setup: apt dependencies, τοπικό .venv, Compat/bin και τον φάκελο Downloads του desktop χρήστη.

Πριν Ξεκινήσεις

  • Χρειάζεται σύνδεση internet για το πρώτο setup.
  • Στο Termux, εγκατέστησέ το από F-Droid και τρέξε termux-setup-storage αν θέλεις πρόσβαση στα Android Downloads.
  • Σε Ubuntu, Kali Linux και Linux Mint χρησιμοποίησε λογαριασμό που μπορεί να τρέξει sudo apt.
  • Η desktop έκδοση δημιουργεί δικό της .venv· μην εγκαθιστάς τα Python packages του project global.

1. Προετοιμασία Συστήματος

Termux

pkg update -y && pkg upgrade -y
pkg install git nano -y
termux-setup-storage

Ubuntu / Kali Linux / Linux Mint

sudo apt update
sudo apt install -y git

2. Clone Και Εγκατάσταση DedSec

Οι ίδιες εντολές χρησιμοποιούνται και στα τέσσερα υποστηριζόμενα συστήματα:

git clone https://github.com/dedsec1121fk/DedSec
cd DedSec
bash Setup.sh

Το Setup.sh εντοπίζει αυτόματα Termux ή desktop Linux. Στο Termux χρησιμοποιεί τον native installer. Σε Ubuntu, Kali Linux και Linux Mint εγκαθιστά τα απαιτούμενα apt packages, δημιουργεί .venv και ετοιμάζει το compatibility layer.

3. Εκκίνηση DedSec

./Run.sh

Χρησιμοποίησε ./Run.sh μετά το setup σε κάθε υποστηριζόμενο σύστημα. Στο desktop Linux ενεργοποιεί αυτόματα το project environment και τα compatibility commands.

Ενημερώσεις

cd ~/DedSec
git pull
bash Setup.sh --update-only
./Run.sh

Αν έχεις κάνει clone το DedSec σε άλλο path, άλλαξε την πρώτη εντολή στο πραγματικό path του project.

Paths Και Διαφορές Πλατφόρμας

  • Termux Downloads: συνήθως ~/storage/downloads/ / Android Download storage.
  • Desktop Linux Downloads: συνήθως ~/Downloads/, μαζί με XDG-customized Downloads paths όπου υποστηρίζονται.
  • Desktop Python: DedSec/.venv/.
  • Desktop compatibility commands: DedSec/Compat/bin/.
  • Shell startup files: το Termux χρησιμοποιεί $PREFIX/etc/bash.bashrc, Ubuntu/Linux Mint συνήθως ~/.bashrc και το Kali μπορεί να χρησιμοποιεί ~/.zshrc.

Τα Android App Launcher, Mobile Desktop, Termux Backup/Restore, Termux Repair Wizard και Mobile Developer Setup είναι μόνο για Termux. Στο Linux εμφανίζονται ως μη εφαρμόσιμα αντί να κάνουν Android αλλαγές στο desktop σύστημα.
