Οδηγός Εγκατάστασης

Βήμα προς βήμα οδηγίες για την εγκατάσταση και τη ρύθμιση του DedSec Project σε Termux για Android, Ubuntu, Kali Linux ή Linux Mint.

Απαιτήσεις

  • Υποστηριζόμενο σύστημα: Termux σε Android, Ubuntu, Kali Linux ή Linux Mint.
  • Αποθηκευτικός Χώρος: Ελάχιστο 6GB ελεύθερος χώρος για την εγκατάσταση του DedSec Project.
  • RAM: Ελάχιστο 2GB.
  • Internet: Required for the first installation and for updates.

Προειδοποίηση αποθηκευτικού χώρου: Η απαίτηση των 6GB αφορά την ίδια την εγκατάσταση του DedSec Project. Scripts που καταγράφουν ή αποθηκεύουν επιπλέον περιεχόμενο—όπως φωτογραφίες, screenshots, βίντεο, ηχογραφήσεις, logs, λήψεις ή άλλα αρχεία που δημιουργούνται—μπορούν να χρειαστούν επιπλέον χώρο πέρα από την απαίτηση των 6GB του project.

Χρόνος εγκατάστασης: Η πλήρης εγκατάσταση μπορεί να διαρκέσει περίπου 20–50 λεπτά, ανάλογα με τη σύνδεσή σας στο internet και τον επεξεργαστή της συσκευής σας.

Termux (Android)

Εγκατάσταση Termux & Πρόσθετων

Για να εγκαταστήσεις APK όπως το F-Droid, ενεργοποίησε την εγκατάσταση από άγνωστες εφαρμογές για τον browser ή τον file manager στις ρυθμίσεις Android.

1. Εγκατάσταση F-Droid

Το F-Droid είναι η προτεινόμενη πηγή για το Termux και τα πρόσθετά του.

Λήψη F-Droid

Πώς Να Εγκαταστήσεις Το F-Droid APK

  1. Κατέβασε το F-Droid APK από τον παραπάνω σύνδεσμο.
  2. Άνοιξε τις Ρυθμίσεις Android και μετά Ασφάλεια ή Εφαρμογές & Ειδοποιήσεις.
  3. Επίτρεψε στον browser ή τον file manager να εγκαθιστά άγνωστες εφαρμογές.
  4. Άνοιξε το APK που κατέβασες και πάτησε Εγκατάσταση.
  5. Άνοιξε το F-Droid και εγκατέστησε το Termux.

2. Εγκατάσταση Πρόσθετων Termux

Για το πλήρες σύνολο λειτουργιών Android, εγκατέστησε το Termux και τα υποστηριζόμενα πρόσθετα από το F-Droid.

Termux Termux:API Termux:Styling

3. Ενημέρωση Termux & Εγκατάσταση Git

pkg update -y && pkg upgrade -y && pkg install git nano -y && termux-setup-storage

4. Κλωνοποίηση DedSec

git clone https://github.com/dedsec1121fk/DedSec

5. Εγκατάσταση DedSec

cd DedSec && bash Setup.sh

6. Άνοιγμα DedSec Αργότερα

cd ~/DedSec && ./Run.sh

Συμβουλή Termux: για μεγάλες εργασίες, κράτησε πατημένο το terminal, άνοιξε το More και ενεργοποίησε το Keep screen on. Μπορείς επίσης να χρησιμοποιήσεις More → Style για εμφάνιση.

Μετά το πρώτο setup στο Termux, επίλεξε prompt, στυλ μενού και γλώσσα και μετά τρέξε το Save DedSec Project ώστε να δημιουργηθεί backup package. Αργότερα μπορείς να ανοίγεις γρήγορα το Αγγλικό ή Ελληνικό μενού γράφοντας e ή g.

Ubuntu

Εγκατάσταση DedSec Σε Ubuntu

Άνοιξε το Terminal και τρέξε τις παρακάτω εντολές με τη σειρά.

1. Εγκατάσταση Απαιτήσεων

sudo apt update && sudo apt install -y git python3 python3-venv python3-pip

2. Κλωνοποίηση DedSec

git clone https://github.com/dedsec1121fk/DedSec

3. Εκτέλεση Setup

cd DedSec && bash Setup.sh

4. Άνοιγμα DedSec Αργότερα

cd ~/DedSec && ./Run.sh

Στο Ubuntu, το Setup.sh δημιουργεί και χρησιμοποιεί το τοπικό .venv του project ώστε να μην αντικαθίσταται η Python που διαχειρίζεται η διανομή.
