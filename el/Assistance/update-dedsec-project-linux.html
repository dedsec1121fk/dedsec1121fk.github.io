Βοήθεια›Ενημέρωση DedSec Project σε Linux

Γρήγορη Περίληψη

Ενημέρωσε Linux checkout χωρίς να αντικαταστήσεις το repository ή να παρακάμψεις το cross-platform dependency refresh.

Έλεγχος Working Tree

cd ~/DedSec
git status

Έλεγξε τις τοπικές αλλαγές πριν το pull ώστε να μην αντικαταστήσεις δουλειά που θέλεις να κρατήσεις.

Pull Και Refresh

git pull
bash Setup.sh --update-only
./Run.sh

Γιατί Τρέχει Ξανά Το Setup

Το Setup.sh --update-only ανανεώνει dependencies και compatibility files μετά από project updates. Ο κανονικός launcher χρησιμοποιεί μετά το ενημερωμένο .venv και Compat/bin.

Custom Clone Path

Αν το project δεν βρίσκεται στο ~/DedSec, μπες πρώτα στον πραγματικό φάκελό του.

Επόμενα Βήματα

Για platform-specific save paths, δες τη σελίδα Μάθε Για Τα Εργαλεία. Για γενικά προβλήματα, επέστρεψε στη Βοήθεια.
