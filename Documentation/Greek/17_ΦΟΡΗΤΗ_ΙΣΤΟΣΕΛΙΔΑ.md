# Ενιαία δημοσίευση ιστοσελίδας, προεπισκοπήσεις και αρχεία SEO / AI

## Επιβεβαιωμένα repositories

Το κύριο repository είναι `dedsec1121fk/dedsec1121fk.github.io` για το `https://ded-sec.space/`. Το ιδιωτικό Test είναι `dedsec1121fk/Test` με προεπιλεγμένη διεύθυνση GitHub Pages `https://dedsec1121fk.github.io/Test/`. Το εφεδρικό repository είναι **`sal-scar/ded-sec`**, με domain `https://ded-sec.online/` — όχι `sal-scars`.

**Το ίδιο ZIP περιέχει τον ενιαίο πηγαίο κώδικα.** Τα τελικά, δημοσιευμένα αρχεία HTML πρέπει να έχουν διαφορετικό πλήρες URL στο canonical, στο sitemap και στα Open Graph previews ανά domain. Αυτό είναι υποχρεωτικό για social previews, επομένως το αυτόματο build παράγει κατάλληλη έκδοση χωρίς αλλαγή στον πηγαίο κώδικα.

## Εντολές

```sh
python3 -m pip install mistune==3.2.0
python3 scripts/build_portable_site.py --target main --output .site-publish
python3 scripts/test_portable_site.py --output .site-publish
```

Άλλαξε `main` σε `test` ή `backup`. Στα GitHub Actions χρησιμοποίησε `--target auto`, ώστε να αναγνωρίζεται αυτόματα το repository μέσω της μεταβλητής `GITHUB_REPOSITORY`. Αν η πραγματική διεύθυνση του GitHub Pages είναι διαφορετική, δώσε `--site-url https://domain.example/path/`.

### Cloudflare Pages

Για το κύριο site, στο Cloudflare Pages ορίζεις build command:

```sh
python3 -m pip install mistune==3.2.0 && python3 scripts/build_portable_site.py --target main --output .site-publish && python3 scripts/test_portable_site.py --output .site-publish
```

Για το backup αλλάζεις `--target main` σε `--target backup`. Βάλε output directory **`.site-publish`** και root directory τη ρίζα του repository. Έλεγξε ότι έχει συνδεθεί σωστά το αντίστοιχο domain. Το Cloudflare δεν εκτελεί αυτόματα τις εντολές του GitHub Actions workflow, άρα η ρύθμιση build στο Cloudflare είναι απαραίτητη.

### Test / GitHub Pages

Το workflow δημοσιεύει στο GitHub Pages μόνο όταν τρέχει στο `dedsec1121fk/Test`. Στο Test βάζουμε `noindex` και αποκλεισμό crawling στο `robots.txt`. Δεν προωθούμε το Test στην Google. Το ίδιο workflow ελέγχει κώδικα και στα τρία repositories, αλλά δεν επιχειρεί να ενεργοποιήσει GitHub Pages στο main ή backup, όπου χρησιμοποιείται custom-domain hosting.

## Τι παράγεται

Περιλαμβάνονται `sitemap.xml`, `robots.txt`, `llms.txt`, `llms-full.txt`, `deployment-manifest.json`, αυτοτελείς προεπισκοπήσεις HTML για τα μαθήματα στα Αγγλικά/Ελληνικά, εικόνες OG 1200×630, meta τίτλοι, περιγραφές, canonical URLs και Twitter cards. Οι σελίδες εκμάθησης έχουν επιλογή **Κοινοποίηση / Προεπισκόπηση** που δείχνει σταθερό δημόσιο URL. Το fragment `#read:ID` δεν είναι κατάλληλο ως μοναδικό URL προεπισκόπησης για chat εφαρμογές.

Οι παλιές σελίδες `/Pages/`, `/Assistance/`, `/el/Pages/` συνεχίζουν να υπάρχουν. Τα εσωτερικά αρχεία και σύνδεσμοι λειτουργούν με σχετικά μονοπάτια και offline μέσω τοπικού HTTP server. Τα social previews απαιτούν πραγματικά προσβάσιμο HTTPS URL. Η καταχώριση AI μέσω `llms.txt` δεν είναι εγγυημένη από καμία πλατφόρμα.

Πριν προωθήσεις αλλαγές στο κύριο site, εκτέλεσε `python3 scripts/test_portable_site.py --output .site-publish` και τους υπάρχοντες αυστηρούς ελέγχους γνώσης. Εξωτερικοί ελεγκτές Facebook, Telegram ή Discord μπορεί να διατηρούν προσωρινά αποθηκευμένη παλαιότερη προεπισκόπηση. Μην προσθέτεις προσωπικές πληροφορίες, απόρρητα δεδομένα ή μη επιτρεπόμενο περιεχόμενο.
