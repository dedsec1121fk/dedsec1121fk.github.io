Το Test είναι `dedsec1121fk/Test` με προεπιλεγμένη διεύθυνση GitHub Pages `https://dedsec1121fk.github.io/Test/`. **Το ίδιο ZIP περιέχει τον ενιαίο πηγαίο κώδικα.** Τα τελικά, δημοσιευμένα αρχεία HTML πρέπει να έχουν διαφορετικό πλήρες URL στο canonical και στα Open Graph previews ανά domain. Αυτό είναι υποχρεωτικό για social previews, επομένως το αυτόματο build παράγει κατάλληλη έκδοση χωρίς αλλαγή στον πηγαίο κώδικα.

## Εντολές

```sh
python3 -m pip install mistune==3.2.0
python3 scripts/build_portable_site.py --target main --output .site-publish
python3 scripts/test_portable_site.py --output .site-publish
```

Άλλαξε `main` σε `test` ή `backup`. Στα GitHub Actions χρησιμοποίησε `--target auto`, ώστε να αναγνωρίζεται αυτόματα το repository μέσω της μεταβλητής `GITHUB_REPOSITORY`. Αν η πραγματική διεύθυνση του GitHub Pages είναι διαφορετική, δώσε `--site-url https://domain.example/path/`.

### Cloudflare Pages

Για το κύριο site, στο Cloudflare Pages ορίζεις build command:

```sh
python3 -m pip install mistune==3.2.0 && python3 scripts/build_portable_site.py --target main --output .site-publish && python3 scripts/test_portable_site.py --output .site-publish
```

Για το backup αλλάζεις `--target main` σε `--target backup`. Βάλε output directory **`.site-publish`** και root directory τη ρίζα του repository. Έλεγξε ότι έχει συνδεθεί σωστά το αντίστοιχο domain. Το Cloudflare δεν εκτελεί αυτόματα τις εντολές του GitHub Actions workflow, άρα η ρύθμιση build στο Cloudflare είναι απαραίτητη.

### GitHub Actions — παραγωγική δημοσίευση στο Cloudflare Pages

Το κύριο repository `dedsec1121fk/dedsec1121fk.github.io` δημοσιεύεται και μέσω του υπάρχοντος `.github/workflows/static.yml`. Σε push του `main` ή χειροκίνητο **Run workflow** (`workflow_dispatch`), εκτελούνται πρώτα οι έλεγχοι μαθημάτων, κώδικα, δημιουργίας `.site-publish`, συνδέσμων/SEO και Chromium. Μόνο αν περάσουν, το `cloudflare/wrangler-action@v4` ανεβάζει το ελεγμένο build στο **υπάρχον** Cloudflare Pages project `dedsec1121fk-github-io` του `https://ded-sec.space/`, στον κλάδο παραγωγής `main`. Το account ID δεν είναι μυστικό· το GitHub Actions secret `CLOUDFLARE_API_TOKEN` έχει περιορισμένα δικαιώματα Cloudflare Pages Edit και δεν πρέπει ποτέ να αποθηκεύεται στον κώδικα ή στα logs.

Δεν δημιουργείται δεύτερο workflow ούτε ενεργοποιείται GitHub Pages στο κύριο ή εφεδρικό repository. Αν αποτύχουν οι έλεγχοι ή λείπει/λήξει το secret, το GitHub deployment σταματά και μένει διαθέσιμη η προηγούμενη έκδοση. Μετά την επιβεβαίωση επιτυχούς deployment από GitHub Actions, απενεργοποιούνται μόνο τα επιπλέον αυτόματα production builds του Cloudflare Git integration, χωρίς αποσύνδεση repository ή domain. Για επαναφορά, κάνουμε revert στο `main` και ξανατρέχουμε το workflow ή επιλέγουμε προηγούμενο deployment από το Cloudflare. Ελέγχουμε το τελικό βήμα του GitHub Actions, την κατάσταση στο Cloudflare και την ιστοσελίδα `https://ded-sec.space/` σε κινητό και στο Forum.

### Test / GitHub Pages

Το workflow δημοσιεύει στο GitHub Pages μόνο όταν τρέχει στο `dedsec1121fk/Test`. Στο Test βάζουμε `noindex` και αποκλεισμό crawling στο `robots.txt`. Δεν προωθούμε το Test στην Google. Το ίδιο workflow ελέγχει τον κώδικα και στα τρία repositories, δημοσιεύει μέσω Wrangler στο Cloudflare Pages μόνο το κύριο repository και δεν ενεργοποιεί GitHub Pages στο main ή backup.

## Τι παράγεται

Περιλαμβάνονται `sitemap.xml`, `robots.txt`, `llms.txt`, `llms-full.txt`, `deployment-manifest.json`, αυτοτελείς προεπισκοπήσεις HTML για τα μαθήματα στα Αγγλικά/Ελληνικά, εικόνες OG 1200×630, meta τίτλοι, περιγραφές, canonical URLs και Twitter cards. Οι σελίδες εκμάθησης έχουν σταθερές διαδρομές HTML· τα κουμπιά Κοινοποίηση / Προεπισκόπηση έχουν αφαιρεθεί. Sitemap και LLM αρχεία δείχνουν μόνο στην κύρια διεύθυνση `https://ded-sec.space/`, ακόμη και στα πακέτα Test/backup. Τα canonical/OG HTML συνεχίζουν να ακολουθούν το περιβάλλον. Το fragment `#read:ID` δεν είναι κατάλληλο ως μοναδικό URL προεπισκόπησης για chat εφαρμογές.

Οι παλιές σελίδες `/Pages/`, `/Assistance/`, `/el/Pages/` συνεχίζουν να υπάρχουν. Τα εσωτερικά αρχεία και σύνδεσμοι λειτουργούν με σχετικά μονοπάτια και offline μέσω τοπικού HTTP server. Τα social previews απαιτούν πραγματικά προσβάσιμο HTTPS URL. Η καταχώριση AI μέσω `llms.txt` δεν είναι εγγυημένη από καμία πλατφόρμα.

Πριν προωθήσεις αλλαγές στο κύριο site, εκτέλεσε `python3 scripts/test_portable_site.py --output .site-publish` και τους υπάρχοντες αυστηρούς ελέγχους γνώσης. Εξωτερικοί ελεγκτές Facebook, Telegram ή Discord μπορεί να διατηρούν προσωρινά αποθηκευμένη παλαιότερη προεπισκόπηση. Μην προσθέτεις προσωπικές πληροφορίες, απόρρητα δεδομένα ή μη επιτρεπόμενο περιεχόμενο.
