# Ασφάλεια, ιδιωτικότητα και διαχωρισμός συστημάτων

Το Test παραμένει δοκιμαστικό περιβάλλον. Όλες οι HTML πρέπει να δηλώνουν `noindex,nofollow`. Δεν προσθέτουμε `CNAME`, `sitemap*` ή `llms*`. Η τοπική βιβλιοθήκη δεν χρειάζεται σύνδεση χρήστη, API, tracking ή online AI. Αγαπημένα και επιλογές εμφάνισης αποθηκεύονται μόνο στο πρόγραμμα περιήγησης· αν το storage απενεργοποιηθεί, ο χρήστης εξακολουθεί να μπορεί να διαβάζει.

Τα αρχικά κείμενα, οι άδειες και οι συντελεστές διατηρούνται. Ούτε ο importer ούτε ένα AI πρέπει να εμφανίζει το Test ως παραγωγική ιστοσελίδα DedSec. Οι κανονικοί σύνδεσμοι DedSec και GitHub Sponsors είναι δημόσιοι προορισμοί που ανοίγει ο χρήστης, όχι αόρατα αιτήματα.

Απαγορεύεται να μπουν στα αρχεία data μυστικά, tokens, οικονομικά στοιχεία, προσωπικοί φάκελοι και ιδιωτικές συνομιλίες. Πριν από πιθανή μεταφορά των αρχικών πηγών έλεγξε ευαίσθητο περιεχόμενο και άδειες τρίτων. Κράτησε δικαιώματα δημιουργών και εκπαιδευτικό χαρακτήρα των θεμάτων ασφάλειας.

Οι καταλήξεις `.py` και `.sh` στα εικονίδια είναι συμβολικοί τίτλοι ιστοσελίδας, όχι αυτόματες εντολές. Μην εκτελείς κώδικα από imported υλικό χωρίς προηγούμενη επιθεώρηση. Η τεκμηρίωση αυτή δεν αποτελεί έγκριση διαγραφής του Developer Mind.
