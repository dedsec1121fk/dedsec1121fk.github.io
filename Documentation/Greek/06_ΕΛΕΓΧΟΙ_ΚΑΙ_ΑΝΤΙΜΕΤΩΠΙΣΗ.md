# Έλεγχοι, προβλήματα και ανάκτηση

## Τι κάνει το GitHub Actions
Η ροή εκτελεί `scripts/import_dedsec.py`, `scripts/validate.py` και syntax checks JavaScript και στη συνέχεια δημοσιεύει τον ιστότοπο. Αν ο importer άλλαξε περιεχόμενο, το αποθηκεύει στο Test. Το `dedsec/.full-import-ready` πρέπει να γράφει `GalaxyV3`: έτσι αποφεύγεται νέο clone σε κάθε αλλαγή. Το αρχικό site διαβάζεται δημόσια, χωρίς πρόσβαση στα ιδιωτικά δεδομένα του Developer Mind.

## Πριν τη δημοσίευση
Εκτέλεσε `python3 scripts/validate.py` μετά την εισαγωγή και προαιρετικά `python3 -m http.server 8765`. Έλεγξε αρχική και δύο HTML οδηγούς (EN/EL), 3 εικονίδια στο κινητό, 6 στον υπολογιστή, πλήρη ονόματα, εναλλαγή μαύρου/λεβάντας, κανονική κύλιση, κείμενα, εικόνες, footer, Sponsor Us και μυστικό επτά πατημάτων με επαναφορά.

Έλεγξε επίσης την αναζήτηση ελληνικών/αγγλικών όρων, την εμφάνιση Markdown, την απουσία αποθήκευσης αγαπημένων και την τοπική λειτουργία μετά το κλείσιμο του Internet. Οι εξωτερικές αναφορές απαιτούν δίκτυο, αλλά όχι η δική μας βιβλιοθήκη.

## Εσωτερική σελίδα χωρίς θέμα
Δες στο Network του browser αν φορτώθηκαν `merged-retro.css` και `merged-retro.js` χωρίς 404. Το CSS πρέπει να εμφανίζεται **μετά** από τα αρχικά styles. Έλεγξε τη διαδρομή `../` ή `../../` και το marker της εισαγωγής. Μη βάζεις δύο ίδια headers ή δύο footers για να «μπαλώσεις» πρόβλημα.

## Αποτυχία Actions
Δες πρώτα ποιο βήμα απέτυχε: clone, Python validation, JavaScript, commit ή Pages. Διόρθωσε την αιτία πριν ξανατρέξεις, για να μη σπαταλήσεις το όριο των 200 λεπτών. Για επιστροφή προτίμησε `git revert` με νέο commit και επανέλεγξε τον ιστότοπο.
