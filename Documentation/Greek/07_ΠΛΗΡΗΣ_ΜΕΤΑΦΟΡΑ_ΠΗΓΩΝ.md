# Πλήρης μεταφορά Developer Mind και αυστηρός έλεγχος

## Τι υπάρχει ήδη και τι λείπει
Το Test περιέχει τη λειτουργική, δίγλωσση βιβλιοθήκη του website. Δεν σημαίνει ότι έχει μεταφερθεί κάθε αρχικό Markdown, Python script, εργαλείο και αρχείο οδηγιών του ιδιωτικού Developer-Mind-Project. **Δεν διαγράφουμε ούτε μετονομάζουμε το παλιό repository** χωρίς νέα εντολή του ιδιοκτήτη.

## Διαδικασία σε υπολογιστή ή Termux
1. Πάρε το πλήρες, ενημερωμένο ιδιωτικό repository με εξουσιοδοτημένο τρόπο. Έλεγξε το Git SHA και τους φακέλους με τη βασική ύλη, τα πρωτότυπα παραδείγματα και τα docs.
2. Από τη ρίζα του Test εκτέλεσε `python3 scripts/migrate_developer_mind.py /διαδρομή/Developer-Mind-Project`. Η διαδικασία αντιγράφει τις αρχικές πηγές στον `source/developer-mind/` **χωρίς** τα Git internals και δημιουργεί μητρώο SHA-256. Δεν σβήνει τα παλιά.
3. Έλεγξε το `source/developer-mind-manifest.json` για πλήθος, paths, hashes, άδειες, scripts και ύποπτα προσωπικά ή μυστικά δεδομένα πριν από δημόσια διάθεση.
4. Εκτέλεσε `python3 scripts/migrate_developer_mind.py --verify /διαδρομή/Developer-Mind-Project` και περίμενε ρητό αποτέλεσμα ισότητας.
5. Αποθήκευσε τις αλλαγές στο Test με Git commits, χωρίς να αλλοιώσεις το κανονικό site. Έλεγξε και την αναζήτηση offline.
6. Κράτησε δεύτερο αντίγραφο. Μόνο μετά από πλήρη έλεγχο ρωτάμε ξανά τον ιδιοκτήτη αν θέλει διαγραφή του άλλου repository.

## Γιατί δεν σβήνουμε «διπλά» αρχεία αυτόματα
Το ίδιο περιεχόμενο μπορεί να έχει άλλη διαδρομή που χρησιμοποιείται από παραπομπές. Κείμενα σε δύο γλώσσες δεν είναι διπλά. Ακόμη και ίδιο hash δεν δικαιολογεί αυθαίρετη κατάργηση: επιθεώρησε τον σκοπό των εγγραφών και κράτησε έγκυρες αναφορές.
