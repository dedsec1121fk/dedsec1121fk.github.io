# Χάρτης συστήματος, ανακατασκευή και λειτουργία

Το κεφάλαιο περιγράφει την τρέχουσα υλοποίηση και αντικαθιστά τις παλιές χρονολογικές σημειώσεις του. Όλες οι διαδρομές είναι σχετικές με τη ρίζα repository. Η δημόσια ιστοσελίδα είναι στατική εφαρμογή HTML/CSS/JavaScript με Python pipeline δημοσίευσης. Οι προαιρετικοί λογαριασμοί λειτουργούν σε ξεχωριστό Cloudflare Worker με D1. Το `cloudflared` είναι πρόγραμμα tunnel· η σύνδεση Cloudflare δεν προσθέτει βάση στο στατικό GitHub Pages ούτε απεριόριστο email/χώρο.

## Πώς συγκροτήθηκε

Οι υπάρχοντες οδηγοί DedSec και οι ελληνικές εκδοχές διατηρήθηκαν στο `DedSec-Project-Website/dedsec/`. Κοινή αρχική και επίπεδο εμφάνισης συνδέουν αυτούς τους οδηγούς, την εκπαιδευτική βιβλιοθήκη και το ενσωματωμένο `TikDev.html`. Αρχειοθετημένα παραδείγματα και δίγλωσσες συγγραφικές επεκτάσεις τροφοδοτούν τον κατάλογο. Το build παράγει φορητές στατικές σελίδες και crawler metadata από τοπικές πηγές, χωρίς νέα λήψη του αρχικού ZIP ή upstream clone σε κάθε release.

Η διεπαφή χρησιμοποιεί κοινή πλοήγηση, θέματα και συναίνεση αντί ανεξάρτητες υλοποιήσεις ανά άρθρο. Η γνώση φορτώνεται όταν ζητείται ανάγνωση/αναζήτηση. Η ετοιμότητα βασικών σελίδων και μικρή επαληθευμένη offline cache αποφεύγουν τη λήψη ολόκληρου του αρχείου κατά την είσοδο. Οι λογαριασμοί προσθέτουν ιδιωτική προέλευση, όρια βάσης και κρυπτογραφημένες ανταμοιβές, χωρίς δημόσια δεδομένα χρηστών.

## Σελίδες, πλοήγηση και εμφάνιση

Η αρχική περιέχει 22 κύριες εγγραφές launcher και ομάδα Others. Cookies, Save DedSec και λογαριασμοί χρησιμοποιούν την υπάρχουσα ενότητα Others. Τα έργα ιδρυτή αποτελούν κλειστή αναδιπλούμενη ενότητα του άρθρου του. Το TikDev είναι μέρος της ιστοσελίδας, με online ανακάλυψη δημόσιων repositories. Οι εξωτερικοί σύνδεσμοι footer δεν επιτρέπουν deployment σε εκείνα τα repositories.

Routes όπως `#home`, `#library`, `#category:…`, `#read:ID` αποδίδονται στην κοινή εφαρμογή. Οι εισαγμένοι οδηγοί είναι φυσικά HTML· aliases διατηρούν παλιές διαδρομές `Pages/`, `el/Pages/` και Assistance. Τα `learn/en/ID.html` και `learn/el/ID.html` είναι στατικά crawlable previews. Τα aliases δεν δημιουργούν πρόσθετα μαθήματα στον κατάλογο.

Η μπάρα έχει Search, Theme, Language, Account. Το Back εμφανίζεται πάνω δεξιά μέσα στις υποσελίδες, με ασφαλή προορισμό σε άμεσο σύνδεσμο. Τα Copy διατηρούν την υπάρχουσα εμφάνιση οδηγού, ακριβές κείμενο εντολών, clipboard fallback και ειλικρινή αποτυχία. Οι τίτλοι χρησιμοποιούν κεφαλαίο αρχικό με διατήρηση ονομάτων προϊόντων. Τελευταίες σειρές ενός/δύο εικονιδίων κεντράρονται. Panels περιεχομένου/εμπιστοσύνης παραμένουν διαφανή με αναγνώσιμο code/input contrast. Μην επαναφέρεις Share/Preview ή το αφαιρεμένο κάτω Main Website.

Θέμα, γλώσσα και συναίνεση είναι τοπικές προτιμήσεις, όχι authentication. Διάβασε τα πραγματικά localStorage keys στα modules πριν τα αλλάξεις· σημειώσεις, recovery codes και κωδικοί δεν επιτρέπονται εκεί. Η συναίνεση ελέγχει προαιρετικά εξωτερικά refreshes, ενώ το bundled περιεχόμενο παραμένει αναγνώσιμο. Η μετάφραση εισαγμένων άρθρων ευθυγραμμίζεται με την αρχική. Τα εικονίδια navbar υπάρχουν στο HTML πριν τα scripts.

## Ροή αναζήτησης, ανάγνωσης και εκκίνησης

Το shell φορτώνει θέματα/readiness και τα presentation dependencies της τρέχουσας σελίδας. Σε δημοσιευμένο HTTPS/localhost το startup manifest προετοιμάζει μόνο βασικές σελίδες και απαραίτητα τοπικά assets. Ο loader μετρά πρόοδο πόρων, περιμένει fonts/images/styles και paint, προσφέροντας Retry/Continue σε αποτυχία. Έχει κεντρικό λογότυπο και πολύχρωμη μπάρα πάνω σε σταθερό γαλαξία. Δεν έχει τεχνητή καθυστέρηση ούτε εγγυάται μηδενικό lag σε κάθε συσκευή.

Η γνώση/αναζήτηση φορτώνει διαδοχικά τα inert catalogues, εφαρμόζει εμπλουτισμούς και κανονικοποιεί τον ενεργό κατάλογο σε μικρά batches. Η αναζήτηση ενώνει δημόσιες παραγράφους και μαθήματα. Τα `test_knowledge_search.mjs` ελέγχουν μορφές όπως `"exact phrase"`, `lang:en`, `type:page`, `in:title`, `topic:website`, OR και εξαιρέσεις. Η ανακάλυψη repositories TikDev είναι ξεχωριστή online λειτουργία.

Τα αποτελέσματα διατηρούν ολόκληρα σχετικά αποσπάσματα. Τα δημόσια fragments μεταφέρουν locator αποσπάσματος, ποτέ ιδιωτικό περιεχόμενο. Το `page-controls.js` αντιστοιχίζει τόνους/διαστήματα σε DOM ranges, ανοίγει περιβάλλοντα details και επισημαίνει/μετακινεί στον στόχο. Χρησιμοποιεί text nodes ώστε να μην εισάγει markup query. Σταθερά IDs συνδέουν SPA και previews. Η βασική offline cache επαληθεύει hashes και ενεργοποιείται μετά την επιτυχή ολοκλήρωση του bundle. Ζητημένη γνώση μπορεί να μείνει στην cache browser· δεν γίνεται προληπτική λήψη όλου του αρχείου.

## Ανακατασκευή δημόσιας ιστοσελίδας από καθαρό checkout

1. Πάρε ολόκληρο το εξουσιοδοτημένο repository με ιστορικό: `git clone --branch main https://github.com/dedsec1121fk/Test.git`, μετά `cd Test`. Κατέγραψε commit. Μην το αντικαταστήσεις με άδειο framework.
2. Εγκατάστησε Python 3.10+ και Node 24. Δημιούργησε απομονωμένο Markdown περιβάλλον και ακολούθησε ακριβώς το κεφάλαιο 03. Χτίσε με `--target test`, χωρίς συμπέρασμα παραγωγικού στόχου από footer.
3. Έλεγξε `.site-publish/deployment-manifest.json`: βάση Test είναι `https://dedsec1121fk.github.io/Test/`, όχι ο παλιός hostname πηγών. Τα source social markers αντικαθίστανται στο build.
4. Σέρβιρε μέσω localhost HTTP. Έλεγξε αρχική, εισαγμένο άρθρο, δύο γλώσσες/θέματα, reader, συνολική αναζήτηση και static preview. Έλεγξε Copy, Back, συναίνεση, details, σταθερό φόντο και στενές οθόνες.
5. Στο Test επίλεξε GitHub Actions ως πηγή Pages αν δεν είναι ήδη ρυθμισμένο. Το workflow χρειάζεται Pages permissions και δημοσιεύει μετά τους ελέγχους. Επιβεβαίωσε το συγκεκριμένο επιτυχημένο run και άνοιξε το πραγματικό HTTPS Test.
6. Διατήρησε noindex. Το build παράγει `sitemap.xml`, `robots.txt`, `llms.txt`, `llms-full.txt` και previews ανά profile· εξέτασε αυτά τα παραγόμενα αρχεία, όχι παλιές source διευθύνσεις. Ποτέ ιδιωτικά δεδομένα στα crawler αρχεία.

Η γενική ιστοσελίδα ανακατασκευάζεται χωρίς βάση. Το στατικό account παραμένει αποσυνδεδεμένο, με προσωρινό TXT preview στη μνήμη και σύνδεσμο ιδιωτικής πύλης. Τα disabled forms δεν συλλέγουν προσωπικά στοιχεία στη στατική προέλευση.

## Ανακατασκευή ή ενημέρωση ιδιωτικών λογαριασμών

Ο τρέχων Worker Test είναι `dedsec-test-accounts` στο `dedsec-project.workers.dev`. Οι μοναδικές portal routes είναι `/dedsec/Pages/account.html` και `/dedsec/el/Pages/account.html`· το API αρχίζει `/api/account/`. Η D1 συνδέεται ως `DB`. Το `account-service/wrangler.example.jsonc` καταγράφει τα σημερινά Test IDs και το ωριαίο cleanup. Μην αντιγράφεις το D1 ID σε άσχετη εγκατάσταση.

Για νέα εγκατάσταση δημιούργησε Free Worker και D1 στον λογαριασμό ιδιοκτήτη· ρύθμισε νέο όνομα/database ID και αντίστοιχα portal/static URLs σε κώδικα/config. Δημιούργησε Turnstile widget για τον ακριβή hostname και actions `register`, `login`, `recover`. Εφάρμοσε 0001, 0002, 0003 μία φορά με τη σειρά στην άδεια βάση. Στο υπάρχον Test τα 0001/0002 εφαρμόστηκαν μέσω D1 API: μετά τον έλεγχο schema εφάρμοσε μόνο 0003. Το `d1_migrations` του Wrangler είναι διαφορετικό από το δικό μας `account_schema_migrations`· μην αφήσεις Wrangler να επαναλάβει παλιά migrations σε βάση αρχικοποιημένη με API.

Χρησιμοποίησε τρέχον Wrangler ή authenticated Cloudflare API. Για εκτέλεση ενός συγκεκριμένου αρχείου από `account-service/`: `wrangler d1 execute dedsec-accounts --remote --config wrangler.example.jsonc --file migrations/0003_account_capacity_and_birth.sql`, μόνο αφού αποδείξεις ότι υπάρχουν 0001/0002 και απουσιάζει 0003. Σε νέα εγκατάσταση βάλε το σωστό νέο όνομα βάσης και εκτέλεσε τα τρία αρχεία με σειρά. Πάρε ιδιωτικό backup, απενεργοποίησε προσωρινά την εγγραφή κατά το migration, έλεγξε ledger και `PRAGMA table_info(account_users)` και μετά εγκατάστησε συμβατό Worker. Η ενέργεια αλλάζει schema και ποτέ δεν πρέπει να στοχεύει κατά λάθος παραγωγή.

Ρύθμισε `SERVICE_MODE`, `TURNSTILE_SITE` και D1. Απαραίτητα secrets είναι `PASSWORD_PEPPER`, `HMAC_SECRET`, `TURNSTILE_SECRET` και για ανταμοιβές `SPONSOR_KEY`. Σε νέα εγκατάσταση δημιούργησε ιδιωτικά ισχυρά ανεξάρτητα κλειδιά. Σε υπάρχουσα κληρονόμησε τα secrets κατά το upload έκδοσης· μην τα εξάγεις ή αντικαθιστάς. Διατήρησε compatibility και όλα τα bindings, επειδή δεν αντιγράφονται αυτόματα σε νέο Worker version. Modules είναι Worker, crypto, limits, ciphertext catalogue και εισαγόμενο account core. Το upload δεν εκτρέπει από μόνο του traffic. Μην γράφεις προσωπικά δεδομένα σε logs και διατήρησε cleanup `17 * * * *`.

Το δημόσιο catalogue είναι κρυπτογραφημένο με κλειδί ιδιοκτήτη. Νέο κλειδί δεν το αποκρυπτογραφεί. Χρειάζεται το αντίστοιχο ιδιωτικό recovery key ή επανασυσκευασία αρχικών scripts με `scripts/package_sponsors.py`. Το `--help` εξηγεί manifest/source-dir/key-file/output/release· πηγές, manifest και κλειδί μένουν εκτός Git. Σε νέα εγκατάσταση χωρίς αυτά χρησιμοποίησε άδειο catalogue και κράτα rewards μη διαθέσιμα. Το ciphertext δεν ανακατασκευάζει από μόνο του χαμένο plaintext.

Το προαιρετικό email απαιτεί `MAIL_API_KEY`, `MAIL_FROM` για Resend. Η σύνδεση Cloudflare δεν επαρκεί. Επιβεβαίωσε sender domain και σύνδεσε δωρεάν πάροχο πριν ενεργοποιήσεις πραγματικά rewards. Η εφαρμογή δεν χρειάζεται/ενεργοποιεί πληρωμένο Cloudflare outbound email. Οι δωρεάν πάροχοι έχουν όρια/διακοπές· έλεγξε τρέχουσα τιμολόγηση και quotas πριν τη δημοσίευση. Λεπτομέρειες και χειρισμός αποτυχίας στο κεφάλαιο 21.

## Λειτουργία και ανάκτηση

Κράτα release record με source commit, Pages run, Worker version, migration ledger και μη μυστικά IDs. Secrets και κρυπτογραφημένα ιδιωτικά backups βάσης αποθηκεύονται σε χώρο ανάκτησης ιδιοκτήτη έξω από Git· το δημόσιο repository δεν είναι user backup. Δοκίμασε επαναφορά σε απομονωμένη βάση. Τα TXT/ZIP exports δεν επαναφέρουν credentials, referrals ή sessions.

Στους 300 υπάρχοντες λογαριασμούς σταματά η εγγραφή· διαγραφή ελευθερώνει θέση. Δεν είναι όριο 300 εγγραφών συνολικά στην ιστορία. Η ημερήσια δραστηριότητα μετρά μοναδικούς λογαριασμούς ανά ημερομηνία Αθήνας, όχι ταυτόχρονες συνδέσεις. Παραμένει 444 ανεξάρτητα από το μικρότερο συνολικό όριο. Η διεπαφή δείχνει πραγματικά server counts ή άγνωστο, όχι demo δραστηριότητα. Ο χώρος παραμένει 400 MB συνολικά και 900 KB ανά χρήστη, δεκαδικά· τα 300 προσωπικά ανώτατα αθροίζουν 270 MB.

Σε κολλημένο loader έλεγξε πόρους, hashes και console/network· χρησιμοποίησε τα failure controls. Μην το διορθώνεις φορτώνοντας όλη τη γνώση ή κρύβοντας αποτυχία θέματος. Για αναζήτηση ανανέωσε δημόσιες παραγράφους και έλεγξε effective IDs, φίλτρα/γλώσσα και αποτυχίες φόρτωσης. Για παλιά styles δες content-hashed URLs και service-worker activation. Σε `portal_not_published` επιβεβαίωσε δημοσίευση account HTML στο Pages και αντικατάσταση fingerprinted config από Worker. Σε `email_not_configured` σύνδεσε πάροχο, χωρίς χειροκίνητο verified bypass. Σε conflict εξήγαγε το ασυγχρόνιστο αντίγραφο πριν reload. Στα rewards έλεγξε πρώτα πραγματική επιβεβαίωση, ηλικία referral/δραστηριότητα και δίκτυα, μετά κρυπτογράφηση.

Δημόσιο rollback γίνεται από Git και νέο build. Σε account incident απενεργοποίησε `SERVICE_MODE` ή βάλε γνωστή συμβατή έκδοση διατηρώντας D1. Το 0003 προσθέτει στήλη, άρα ο παλιός Worker με `INSERT INTO account_users VALUES(...)` δεν υποστηρίζει νέες εγγραφές: χρειάζεται ρητές στήλες ή διατήρηση του νέου registration path. Μην αφαιρείς DOB ή tables ως συντόμευση. Επαναφορά D1 γίνεται μόνο από ελεγμένο ιδιωτικό σημείο ανάκτησης με ρητή απόφαση για απώλεια νεότερων δεδομένων.

## Στοιχεία και όρια ελέγχων

Τα tests χρησιμοποιούν πραγματικές SQLite συναλλαγές και ελεγχόμενα transports Turnstile/email. Το Chromium εξετάζει source/generated UI με mock accounts και screenshots. Αυτό τεκμηριώνει συγκεκριμένες συμπεριφορές, όχι ανεξάρτητη πιστοποίηση ασφάλειας, νομική επάρκεια, τέλειες μεταφράσεις ή εγγυημένη δωρεάν χωρητικότητα σε κάθε κίνηση. Πριν τη δημόσια χρήση referrals έλεγξε πραγματικό signup CAPTCHA, email, ωρίμανση δύο ημερών και authenticated λήψεις στο περιβάλλον ιδιοκτήτη. Δήλωσε καθαρά εκκρεμή σύνδεση παρόχου στο release report.

Επίσημες αναφορές: [D1 migrations](https://developers.cloudflare.com/d1/reference/migrations/), [Worker version upload και inherited bindings](https://developers.cloudflare.com/api/resources/workers/subresources/scripts/subresources/versions/methods/create/), [ανάκτηση D1](https://developers.cloudflare.com/d1/reference/time-travel/). Κλείδωσε dependencies και έλεγξε επίσημες αλλαγές πριν μελλοντικά upgrades.
