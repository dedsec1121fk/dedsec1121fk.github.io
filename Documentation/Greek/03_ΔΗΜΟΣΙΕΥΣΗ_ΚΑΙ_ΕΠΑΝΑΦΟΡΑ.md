# Δημοσίευση, offline λειτουργία και επαναφορά

## Τοπική δοκιμή
Κατέβασε ολόκληρο το Test repository. Άνοιξε το `index.html` σε browser ή ξεκίνα από τη ρίζα `python3 -m http.server 8765` και επισκέψου `http://127.0.0.1:8765/`. Σε Termux η εντολή μπορεί να είναι `python` αντί `python3`. Η αναζήτηση δεν χρειάζεται server, λογαριασμό, npm ή εξωτερικά AI APIs.

## GitHub Pages
Το `.github/workflows/static.yml` ελέγχει τον ιστότοπο, εισάγει την δημόσια DedSec ιστοσελίδα μόνο αν άλλαξε το marker, αποθηκεύει τα `dedsec/` αρχεία και δημοσιεύει το static artifact. Το `dedsec/.full-import-ready` καθορίζει την έκδοση εισαγωγής (GalaxyV3). Μην το διαγράφεις χωρίς σοβαρό λόγο. Το αυτόματο commit από GITHUB_TOKEN δεν είναι απαραίτητο να ξεκινήσει νέο workflow.

## Επιτρεπτά και απαγορευμένα
Οι εσωτερικές διαδρομές να είναι σχετικές με το GitHub Pages /Test. Απαγορεύεται η αντιγραφή `CNAME`, `sitemap*` και `llms*`. Το Test είναι περιβάλλον δοκιμής και δεν πρέπει να δείχνει ότι είναι η κύρια παραγωγική έκδοση.

## Επαναφορά
Βρες το τελευταίο καλό SHA και κάνε revert με νέο commit· μην ξαναγράψεις το ιστορικό. Μετά επανέλεγξε σύνταξη, links, αναζήτηση, mobile layout και τα δύο θέματα. Για πλήρες αντίγραφο κράτησε zip με HTML, assets, data, DedSec pages, documentation και scripts.

## Τελική λίστα smoke tests
Αρχική/μαύρο/φωτεινό, τρεις/έξι στήλες, αλλαγή γλώσσας, άνοιγμα ελληνικών και αγγλικών σελίδων, πλήρης τίτλος, σύνδεσμος Sponsor, εξωτερικά links μόνο όπου χρειάζεται, αναζήτηση και αποθηκευμένα μαθήματα, scroll σε code snippets, footer παντού και Easter egg.
