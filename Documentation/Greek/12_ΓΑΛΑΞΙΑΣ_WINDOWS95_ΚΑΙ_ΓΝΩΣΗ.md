# Συντήρηση Windows 95 Γαλαξία και Γνώσης

## Πού γίνεται κάθε αλλαγή
- `assets/galaxy.css`: κοινά χρώματα, σκοτεινότερο μαύρο πέπλο, φωτεινή λεβάντα, font fallback Tahoma/MS Sans Serif/Arial και τετράγωνες γωνίες.
- `assets/starfield-dark.svg`, `assets/starfield-light.svg`: στατικά νεφελώματα, πλανήτες, άστρα, πεταλούδες, δύο διακριτικούς εξωγήινους, δύο σκύλους και ένα σκάφος. Δεν φορτώνονται εξωτερικές εικόνες, ούτε συνεχόμενα animation.
- `assets/ui.css`: απλούστερα εικονίδια, κεντραρισμένοι τίτλοι/υπότιτλοι/κείμενα και αριστερά ευθυγραμμισμένος κώδικας.
- `dedsec/Assets/merged-retro.css`: παλιά HTML, σωστή αντίθεση και διόρθωση του `#merged-lang`. Η πάνω μπάρα είναι αδιαφανής για να μην εμφανίζει γράμματα που κυλούν πίσω της.

Η αισθητική Windows 95 ζητά γραμματοσειρά συστήματος και **δεν** περιλαμβάνει αρχεία Microsoft fonts· στο Android μπορεί να εμφανιστεί fallback. Στο σκοτεινό θέμα κείμενο/εικονίδια `#fafafa`, στο φωτεινό `#111014`. Έλεγξε υπολογισμένο χρώμα τόσο στο κουμπί όσο και στον εσωτερικό κόμβο του.

## Ουσιαστικό περιεχόμενο χωρίς διπλότυπα
Στο `data/methods.js` υπάρχουν 30 διαφορετικές εγγραφές, 15 ελληνικές και 15 αγγλικές. Οι τέσσερις νέες είναι αυθεντικά μαθήματα για έλεγχο CSS και ταυτοποίηση διπλών γνώσεων. Οι υπόλοιπες πρωτότυπες πηγές διατηρούνται. Η `displayTitle(d)` προσθέτει συμφραζόμενα εργαλείου/γλώσσας σε γενικούς επαναλαμβανόμενους τίτλους. Το ίδιο μικρό SQL παράδειγμα μπορεί να έχει νόημα σε διαφορετικές πλατφόρμες· μην διαγράφεις βάσει τίτλου ή απλού hash.

Οι σελίδες γνώσης έχουν κεντραρισμένους τίτλους, υποτίτλους, παραγράφους και λίστες. Ο κώδικας παραμένει αριστερά. Δεν υπάρχουν Αγαπημένα Μαθήματα, ενώ θέμα/γλώσσα/cookies αποθηκεύονται.

## Συντήρηση από άνθρωπο ή AI
1. Εκτέλεσε `python3 scripts/validate.py` και `node --check` για `assets/ui.js`, `data/methods.js`, `scripts/browser_audit.mjs`.
2. Επιθεώρησε το artifact `test-chromium-audit` στα GitHub Actions: δύο θέματα, ελληνική Εγκατάσταση, βιβλιοθήκη, κατηγορία και μάθημα. Έλεγξε πραγματικά χρώματα, γωνίες, κεντράρισμα και οριζόντια υπερχείλιση.
3. Δοκίμασε χωριστά πραγματικό Android· το CI δεν αποδεικνύει κάθε συσκευή ή κάθε παλιό HTML.
