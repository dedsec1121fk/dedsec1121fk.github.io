# Συντήρηση Test: TikDev, φόρτωση, αναζήτηση, φωτεινά πλαίσια και γνώση

Ισχύει **μόνο για το Test**. Αυτός ο οδηγός υπερισχύει παλαιότερων σημειώσεων εμφάνισης που περιγράφουν μονόχρωμα εικονίδια ή πλήρη απουσία περιγραμμάτων. Δεν αλλάζουμε την παραγωγική ιστοσελίδα ούτε διαγράφουμε τα αρχικά έργα χωρίς ρητή έγκριση.

## Αρχεία και ρόλοι

- `index.html`: κοινή πλοήγηση, αρχική, εισαγωγή δέκα δευτερολέπτων, μεταδεδομένα προεπισκοπήσεων.
- `assets/ui.js`: δίγλωσσες επιλογές `APPS`, κατηγορίες `CATS`, λειτουργία γνώσης. Η αναζήτηση βρίσκεται **μόνο στο επάνω μενού** και ανοίγει την υπάρχουσα βιβλιοθήκη `#library`. Δεν υπάρχει χωριστή εφαρμογή ή διαδρομή `#search`.
- `assets/cookie-consent.js`: πρώτα ολοκληρώνεται η εισαγωγή και το γεγονός `dedsec:bootcomplete`, έπειτα εμφανίζεται συγκατάθεση σε νέα επίσκεψη. Η χειροκίνητη επιλογή Cookies παραμένει διαθέσιμη.
- `assets/refinement.css`: κοινά φωτεινά περιγράμματα, τετράγωνες γωνίες, διάφανα panels σε σκοτεινό και φωτεινό θέμα.
- `dedsec/Assets/merged-retro.js`: σωστή λειτουργία FAQ/dropdowns, αντιγραφής εντολών, κοινής εμφάνισης άρθρων.
- `data/en.js`, `data/el.js`: διατηρούμενο αρχείο γνώσης. `data/termux-troubleshooting.js`: νέοι πρωτότυποι δίγλωσσοι οδηγοί. `data/hacking-guide.js`: πρωτότυποι οδηγοί ασφαλούς και εξουσιοδοτημένης μάθησης.
- `tikdev/index.html`: ενσωματωμένο αντίγραφο προσαρμοσμένο από `dedsec1121fk/TikDev`. Το ξεχωριστό repository δεν μεταβάλλεται. Διατηρούμε το `tikdev/LICENSE`.

## Ενσωμάτωση TikDev

Το TikDev χρησιμοποιεί δημόσιο GitHub API. Το να λειτουργεί στατικά δεν σημαίνει ότι ανακαλύπτει νέα GitHub projects χωρίς Internet: σε αποσύνδεση ή rate limit πρέπει να εμφανίζεται σαφής κατάσταση και να μπορεί να επαναληφθεί η προσπάθεια. Δεν χρησιμοποιούμε μυστικά tokens σε HTML ή JavaScript.

Η πάνω μπάρα επαναχρησιμοποιεί οπτικά τον χαρακτήρα DedSec και τις κοινές προτιμήσεις `dedsec:theme`, `dedsec:language`. Τα επιπλέον εργαλεία TikDev (ενδιαφέροντα, φίλτρα, μουσική, ανανέωση) παραμένουν ξεχωριστά. Τα βασικά στατικά κουμπιά έχουν ελληνικά/αγγλικά, ενώ οι περιγραφές GitHub εμφανίζονται στη γλώσσα του δημιουργού τους.

Η μουσική περιλαμβάνει υπάρχοντα YouTube streams, προαιρετικό δικό σου YouTube link και δύο τοπικά παραγόμενους ήχους Web Audio. Δεν υπάρχει αυτόματη σύνδεση στο YouTube χωρίς πάτημα αναπαραγωγής. Οι ήχοι περιβάλλοντος είναι συνθετικοί, όχι ηχογραφημένη βροχή.

Ανανέωση: το κουμπί `dedsec-refresh` ενημερώνει χειροκίνητα το feed. Ο χρήστης μπορεί να επιλέξει αυτόματο έλεγχο ανά 5, 10 ή 20 λεπτά· η προεπιλογή είναι Απενεργοποιημένο. Δεν ενημερώνουμε στο παρασκήνιο χωρίς ορατή καρτέλα.

Προώθηση DedSec: μετά από κάθε **18 κανονικά repositories** (18, 36, 54...) προστίθεται το πολύ μία διακριτά σημειωμένη, επιλέξιμη πρόταση του δημιουργού `dedsec1121fk`. Διατηρούνται οι εξαιρέσεις των starred repositories. Δεν αντικαθιστά άλλα projects και δεν εμφανίζεται στο Saved feed. Ένα σφάλμα της προαιρετικής πρότασης δεν πρέπει να σταματά το κανονικό feed.

## Περιγραφές γνώσης

Η `shortSentence(value,max)` κρατά την **τελευταία ολόκληρη πρόταση** εντός ορίου. Αν η πρώτη πρόταση είναι μεγαλύτερη, δείχνει ολόκληρη την πρώτη, όχι κομμένο κείμενο με ψεύτικη τελεία. Δεν αλλάζει το πλήρες περιεχόμενο μαθήματος και δεν επιτρέπεται η παλιά λύση `slice(0,max)+'.'`.

## Εισαγωγή και Cookies

Η κλάση `booting` κρύβει αρχική, επάνω κουμπιά και footer πριν από την πρώτη εμφάνιση. Φαίνεται μόνο το γαλαξιακό φόντο, το όνομα DedSec Project, το κινούμενο σχέδιο και η μπάρα που γεμίζει πραγματικά σε δέκα δευτερόλεπτα. Μετά την εξαφάνιση της εισαγωγής γίνεται `dedsec:bootcomplete` και μόνο τότε επιτρέπεται η πρώτη ερώτηση Cookies.

## Κοινές προεπισκοπήσεις

Το `scripts/social_previews.py` δημιουργεί στατικά tags σε Αρχική, οδηγούς DedSec και TikDev. Ελέγχουμε `title`, `meta description`, `og:title`, `og:description`, `og:url`, `og:image`, Twitter tags και favicon. Χρησιμοποιούμε το υπάρχον `dedsec/Assets/Images/og/og-dark.jpg` και ένα τοπικό DedSec favicon. Απαγορεύονται πολλαπλά ίδια metadata. Τα paths πρέπει να δείχνουν στο `/Test/`, όχι παραγωγή.

## Συντήρηση, έλεγχος, επαναφορά

```sh
python3 scripts/import_dedsec.py
python3 scripts/social_previews.py
python3 scripts/audit_knowledge.py
python3 scripts/validate.py
node --check assets/ui.js
node --check assets/cookie-consent.js
node --check dedsec/Assets/merged-retro.js
node --check scripts/browser_audit.mjs
python3 -m http.server 8765 --bind 127.0.0.1
```

Οι δοκιμές Chromium βρίσκονται στο `scripts/browser_audit.mjs` και στην GitHub Actions ροή. Ελέγχουμε πραγματικά την επιλογή Cookies μετά τη φόρτωση, αντιγραφή εντολών, αναζήτηση, glow χωρίς στρογγυλά πλαίσια, TikDev, Ελληνικά/Αγγλικά, μουσική, προβολές και κινητό. Αν αποτύχει build, διορθώνουμε στο Test και επαναλαμβάνουμε. Επιστροφή με revert του συγκεκριμένου commit, ποτέ με διαγραφή ιστορικού. Η μετάβαση στο live απαιτεί ρητή έγκριση.
