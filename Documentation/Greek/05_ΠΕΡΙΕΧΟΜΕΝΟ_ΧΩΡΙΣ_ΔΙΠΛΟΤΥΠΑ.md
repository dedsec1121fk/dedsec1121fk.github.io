# Ποιότητα γνώσης και αποφυγή διπλοτύπων

## Ποια αρχεία είναι οι αρχικές πηγές
Οι `dedsec/Pages/`, `dedsec/el/Pages/` και `dedsec/Assistance/` είναι αντίγραφα από την επίσημη ιστοσελίδα DedSec. Όταν αλλάζει η πηγή, ο importer μπορεί να τα ξαναδημιουργήσει. Τα `data/en.js`, `data/el.js` και `data/methods.js` είναι λειτουργικές εκδόσεις της εκπαιδευτικής ύλης που διαβάζονται και χωρίς Internet. Δεν αντικαθιστούν τα αρχικά Markdown, κώδικα και τεκμηρίωση του Developer Mind.

## Πότε κάτι θεωρείται διπλό
Δύο εικονίδια που ανοίγουν ακριβώς την ίδια ενότητα χωρίς άλλη χρησιμότητα προκαλούν σύγχυση. Δύο μαθήματα με το ίδιο `id` είναι λάθος δεδομένα. Πανομοιότυπες παράγραφοι χωρίς πρόσθετη γνώση πρέπει να συγχωνεύονται ή να συνδέονται με παραπομπή. **Η ελληνική μετάφραση του αγγλικού μαθήματος δεν είναι διπλότυπο**· διατήρησε τις δύο γλώσσες.

## Συντήρηση εικονιδίων και μαθημάτων
Ο `APPS` στο `assets/ui.js` ορίζει πλήρη αγγλικό τίτλο, πλήρη ελληνικό τίτλο, εικονίδιο, προορισμό και τύπο. Τα εργαλεία DedSec μπαίνουν πρώτα. Για νέο μάθημα γράψε πραγματικά χρήσιμο περιεχόμενο με δικό του τίτλο και αναγνωριστικό, δημιούργησε ποιοτική απόδοση στα Ελληνικά, ενημέρωσε τα τοπικά indexes και δοκίμασε αναζήτηση και ανάγνωση.

## Κατάργηση
Πριν αφαιρέσεις κάποιο εικονίδιο ή HTML σελίδα έλεγξε τις παραπομπές, τη δεύτερη γλώσσα και τους σελιδοδείκτες. Μην αφαιρείς την άδεια χρήσης, τις αναφορές σε δημιουργούς και πρωτότυπο υλικό για χάρη απλούστερου μενού. Η μεταφορά σε άλλο repository δεν είναι άδεια διαγραφής του αρχικού.

### Ισχύουσα διάταξη και διατήρηση αρχείων (Οκτώβριος 2026)
Σε κατακόρυφο κινητό εμφανίζονται **τρία** εικονίδια ανά σειρά και σε οριζόντια οθόνη/PC **έξι**. Το λογότυπο Black/White αλλάζει ανά θέμα, υπάρχει Αναζήτηση στην κορυφή και ο κοινός γαλαξίας περιέχει τοπικά αστέρια και λεπτή σκοτεινή επίστρωση. Οι παλιές σελίδες έχουν διάφανα περιβλήματα με ημιδιαφανείς κάρτες για αναγνωσιμότητα. Δεν διαγράφουμε καμία πρωτότυπη πηγή Developer Mind πριν από ξεχωριστό τεκμηριωμένο έλεγχο και ρητή εντολή. [Πλήρης συντήρηση](09_ΠΛΗΡΗΣ_ΣΥΝΤΗΡΗΣΗ.md).

### Σφάλματα μεταγλώττισης C# — επέκταση υπάρχουσας ύλης (Οκτώβριος 2026)
Οι υπάρχουσες εγγραφές `059_CS0103`, `060_CS0246`, `061_CS0029` περιλαμβάνουν πλέον ξεχωριστά παραδείγματα αποτυχίας, διορθωμένο κώδικα, αναμενόμενη έξοδο και ελέγχους για εμβέλεια, namespaces/references και μετατροπές τύπων. Οι αρχικές πηγές μένουν στο `Developer's Mind/Keep Programming Alive/Greek/Εγχειρίδιο_Σφαλμάτων/`. Η offline ιστοσελίδα αντικαθιστά το κείμενο στις **ίδιες** εγγραφές μέσω `data/lesson-expansions-errors-csharp.js` πριν από το `data/apply-lesson-expansions.js`. Δεν προστίθενται ID, routes ή ίδιες κάρτες. Το `scripts/validate.py` ελέγχει ελάχιστη βάση 26 επεκτάσεων και ισότιμο πλήθος Αγγλικών/Ελληνικών, αντί για παλιό σταθερό πλήθος. Ο ανεξάρτητος έλεγχος παρακολουθεί διπλότυπα κλειδιά και ταύτιση αρχείων Markdown με την ιστοσελίδα. Έλεγχος: έξι μοναδικά locale/path keys, μία εισαγωγή script, οι δύο γλώσσες και εκτέλεση `python3 scripts/audit_knowledge.py`, `python3 scripts/validate.py` και browser/search tests σε τοπικό checkout. Επαναφορά: αναίρεση του συγκεκριμένου commit, όχι της συγχώνευσης branches.

### Διάγνωση SQL, shell και web — Οκτώβριος 2026
Επεκτείνονται οι **ήδη υπάρχουσες** εγγραφές `064_no_such_column` (SQLite, επιθεώρηση σχήματος και migrations), `076_unbound_variable` (Bash nounset, διαφορά μη ορισμένης/κενής μεταβλητής, Termux) και `096_HTTP_500` (server logs, ασφαλής τοπική προσομοίωση και σωστά retries). Τα ελληνικά/αγγλικά Markdown συγχρονίζονται με έξι ξεχωριστές αντικαταστάσεις στο `data/lesson-expansions-errors-operational.js`, που φορτώνεται μία φορά πριν το `apply-lesson-expansions.js`. Τα αρχικά αναγνωριστικά και οι κάρτες αναζήτησης διατηρούνται. Έλεγχος: ταύτιση έξι Markdown και overlays, δοκιμή SQLite/Bash τοπικά, επιβεβαίωση loopback HTTP server, γνώση/validator και browser smoke tests στις δύο γλώσσες. Για επαναφορά ακύρωσε το συγκεκριμένο commit. Οι υπόλοιπες σύντομες σελίδες δεν χαρακτηρίζονται ολοκληρωμένες.

### Ορθότητα Reverse Engineering — DMR1 και εξουσιοδότηση
Τα αρχικά μαθήματα `Reverse Engineering/Greek/18_LAB.md` και `01_PERMISSIONS.md` (και οι αγγλικές εκδόσεις) συγχρονίζονται με τις offline κάρτες μέσω `data/lesson-expansions-reverse-fixture.js`. Το DMR1 v1 έχει **ακριβώς** τετράbyte υπογραφή, δύο bytes little-endian count και περιορισμένο payload: **χωρίς checksum ή UTF-8 records**. Οι παλιές αναφορές σε ανύπαρκτα `site/labs/` αντικαταστάθηκαν με αυτοτελές πρόγραμμα Python 3. Ο parser απορρίπτει σφάλματα header, count, truncation και επιπλέον bytes· η προβλεπόμενη έξοδος και έξι κακές περιπτώσεις ελέγχθηκαν τοπικά. Το μάθημα αδειών απαιτεί πραγματικό owner/scope/environment/retention/stop condition, χωρίς τεκμαιρόμενη άδεια για ξένα συστήματα. Έλεγχος ισοδυναμίας τεσσάρων Markdown/JS πηγών, εκτέλεση `python3 scripts/audit_knowledge.py`, validators και browser tests σε τοπικό checkout. Δεν ανεβάζουμε πραγματικά private αρχεία ή καταγραφές.

### 200 ενημερωμένα αρχεία — 100 δίγλωσσα ζεύγη γλωσσών (17 Οκτωβρίου 2026)
Στο ίδιο batch επεκτάθηκαν **100 υπάρχοντα αγγλικά** και **100 αντίστοιχα ελληνικά** αρχικά μαθήματα στον φάκελο `Developer's Mind/Keep Programming Alive/{English,Greek}/`. Τα παραδείγματα εξετάζουν συγκεκριμένες λειτουργίες, types, δομές δεδομένων, σφάλματα και περιορισμούς πλατφορμών. Δεν δημιουργήθηκαν νέοι μαθησιακοί τίτλοι, ID ή δεύτερες κάρτες αναζήτησης και δεν άλλαξαν τα paths. Τέσσερα website datasets `data/lesson-expansions-batch-01-languages.js` έως `batch-04-languages.js` περιλαμβάνουν ακριβείς **replace** ενημερώσεις για τις υπάρχουσες εγγραφές (50 entries το καθένα, 25 ζεύγη). Το `index.html` τις φορτώνει πριν από το `data/apply-lesson-expansions.js`.

Μερικά παραδείγματα είναι εκτελέσιμα σε κατάλληλο runtime, ενώ άλλα χαρακτηρίζονται ρητά ως **εννοιολογικά** όταν απαιτείται εξειδικευμένο toolchain. Δεν ισχυριζόμαστε ότι εκτελέστηκαν σε κάθε πλατφόρμα. Κάθε αλλαγμένο Markdown πρέπει να συμφωνεί με το αντίστοιχο website overlay· πριν από τελικό signoff εκτέλεσε `python3 scripts/audit_knowledge.py`, `python3 scripts/validate.py` και browser tests για search, γλώσσες, θέματα και mobile/desktop. Το commit περιλαμβάνει `[skip ci]` για εξοικονόμηση Actions, **όχι** επειδή έγιναν όλα τα integration tests. Για rollback αναιρούμε το συγκεκριμένο commit στο main χωρίς διαγραφή παραγωγής. Οι κοινές μικρές επικεφαλίδες εξυπηρετούν ομοιόμορφη ανάγνωση, όμως μηχανισμοί και ασκήσεις πρέπει να παραμένουν ειδικοί για το θέμα. Υπάρχουν ακόμη σύντομα αρχεία, συνεπώς δεν δηλώνουμε ολοκλήρωση όλου του corpus.

### Ισχύουσα πηγή και ασφαλής αφαίρεση επαναλήψεων
Τα βασικά ευρετήρια της ιστοσελίδας βρίσκονται στα `DedSec-Project-Website/data/en.js` και `el.js` με σταθερά IDs και διαδρομές. Οι στοχευμένες συμπληρώσεις ή αντικαταστάσεις είναι στα `data/lesson-expansions-*.js`, με μοναδικό κλειδί `(γλώσσα, διαδρομή)`. Το `scripts/export_developer_mind.py` παράγει την πραγματική δίγλωσση ύλη κάτω από `Developer's Mind/Keep Programming Alive/{English,Greek}/`. Δεν αρκεί να αλλάξει μόνο το JS: πρέπει να συμφωνεί και το εξαγόμενο Markdown.

Πριν από τους ελέγχους, το `scripts/remove_boilerplate.py` αφαιρεί αναγνωρίσιμες αυτόματες παραγράφους «διερεύνησης / αφετηρίας / επαλήθευσης», μόνο όταν απομένει ουσιαστικό κείμενο τουλάχιστον 450 χαρακτήρων με ενότητα. Δεν δημιουργεί γενικόλογες ασκήσεις για να φτάσει ένα τεχνητό όριο μεγέθους. Όσα μικρά ή επαναλαμβανόμενα μαθήματα απομένουν καταγράφονται ως εκκρεμότητες. Το παλιό `scripts/finish_short_archive.py` είναι σκόπιμα απενεργοποιημένο επειδή παρήγε τυποποιημένο υλικό και δεν πρέπει να ενεργοποιηθεί ξανά.

### Μοναδικά overlays, απόρρητο και διατήρηση κώδικα
Αν δύο overlays στοχεύουν το ίδιο μάθημα, κράτησε μία πληρέστερη έκδοση, όχι δύο συρραμμένα κείμενα. Ο αυτοματισμός κάνει αρχική επιλογή, αλλά ο συντηρητής οφείλει να ελέγχει σημαντικές διαφορές. Δεν διαγράφουμε κανονικά IDs μαθημάτων ούτε πρωτότυπα εκτελέσιμα αρχεία `.py` ή `.sh`. Το `python3 scripts/audit_knowledge.py` ελέγχει κλειδιά, σώματα, γλώσσες και επαναλήψεις· το `python3 scripts/audit_knowledge_depth.py` εξετάζει το πραγματικό δημοσιευμένο κείμενο και την ισότητα με τα Markdown.

### Έλεγχος πριν από τελική έγκριση
**Επιτυχημένο deployment στο Test δεν σημαίνει ότι τελείωσε το knowledge.** Το workflow περιλαμβάνει unit tests, στατικό validation και πραγματικούς ελέγχους Chromium σε κινητό και υπολογιστή. Ο ξεχωριστός αυστηρός έλεγχος `--strict` αναφέρει όσα σύντομα, κενά ή επαναλαμβανόμενα μαθήματα εκκρεμούν. Όσο γράφει NOT READY, δεν δηλώνουμε ολοκληρωμένη βιβλιοθήκη. Διορθώνουμε ανά συγκεκριμένο θέμα και στις δύο γλώσσες, με έγκυρο παράδειγμα, αναμενόμενη συμπεριφορά, αποτυχίες και σαφή όρια πλατφόρμας. Συγκεντρώνουμε τις αλλαγές στο main, εξοικονομούμε GitHub Actions και δεν επεμβαίνουμε στο production χωρίς ξεχωριστή άδεια.

### Υποχρεωτικός ποιοτικός έλεγχος (Οκτώβριος 2026)
Μην εκτελείς ξανά το scripts/finish_short_archive.py: βρέθηκαν επαναλαμβανόμενα τμήματα «διερεύνησης» που μεγάλωναν τα αρχεία χωρίς ουσιαστικές δοκιμασμένες γνώσεις. Το script δεν πραγματοποιεί πλέον τέτοια παραγωγή. Από τη ρίζα εκτέλεσε **python scripts/audit_knowledge_depth.py --strict**. Ελέγχει τα αγγλικά και ελληνικά άρθρα, την ισοδυναμία του website overlay με τα Markdown, επαναλαμβανόμενες παραγράφους, κακοσχηματισμένα code fences, πολύ σύντομες ενότητες, άδειους τίτλους και γενικόλογα τμήματα που αλλάζουν μόνο όνομα θέματος. Ο απλός έλεγχος χωρίς --strict δίνει λίστα εκκρεμοτήτων και **δεν** αποδεικνύει ολοκλήρωση.

Διόρθωσε κάθε αδύναμο ζεύγος άρθρων με πραγματικό παράδειγμα και αντίστοιχη ενημέρωση του website overlay. Δήλωνε σαφώς έκδοση compiler/runtime και πλατφόρμα, ξεχώριζε αναμενόμενη από πραγματικά παρατηρημένη έξοδο και πρόσθεσε ουσιαστική αρνητική δοκιμή. Έπειτα εκτέλεσε validators και browser regression tests πριν χαρακτηρίσεις μια έκδοση ολοκληρωμένη.
