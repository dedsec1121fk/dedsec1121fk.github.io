# Προεπισκοπήσεις συνδέσμων — καθολικό build

Οι προεπισκοπήσεις δημιουργούνται από το `scripts/build_portable_site.py`, χωρίς σταθερό/λανθασμένο Test URL μέσα στα αρχεία πηγαίου κώδικα. Το παλιό `scripts/social_previews.py` οδηγεί πλέον στο ίδιο ασφαλές build.

Δες τις πλήρεις οδηγίες **[Φορητή ιστοσελίδα, sitemap και AI](17_ΦΟΡΗΤΗ_ΙΣΤΟΣΕΛΙΔΑ.md)** για κύριο, Test και backup repository, Cloudflare Pages και GitHub Pages. Για δοκιμή:

```sh
python3 scripts/build_portable_site.py --target test --output .site-publish
python3 scripts/test_portable_site.py --output .site-publish
```

Κάθε σελίδα έχει ιδιαίτερο τίτλο, περιγραφή, canonical URL, Open Graph/Twitter και προεπισκόπηση JPEG 1200×630. Τα μαθήματα διαθέτουν σταθερούς δημόσιους συνδέσμους. Οι υπηρεσίες κοινωνικών δικτύων ενδέχεται να διατηρούν παλιές προεπισκοπήσεις στη μνήμη τους έως ότου ανανεωθούν.
