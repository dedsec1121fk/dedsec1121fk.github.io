# Επιμελημένη γνώση για χρήση χωρίς Internet — Οκτώβριος 2026

## Τι αλλάξαμε και γιατί

Ο παλιός κατάλογος περιλάμβανε 1.188 εγγραφές ανά γλώσσα, αλλά πολλά Markdown μαθήματα είχαν ελάχιστες πληροφορίες, κενές ενότητες ή τυποποιημένες παραγράφους. Αντί να προσθέσουμε τεχνητό κείμενο, **ενώσαμε** συναφείς ασκήσεις και σημειώσεις σε μεγαλύτερους οδηγούς ανά θέμα. Η έκδοση αυτή διατηρεί 669 καταχωρίσεις στα Ελληνικά και 669 στα Αγγλικά: **422 πλήρεις Markdown οδηγούς και 247 αρχεία πηγαίου κώδικα/αναφοράς ανά γλώσσα**. Ο χωριστός Hacking Guide (140 κεφάλαια ανά γλώσσα), ο οδηγός Termux και οι 30 καταχωρίσεις μεθοδολογίας παραμένουν εκτός αυτού του αριθμού.

Οι 559 παλιές διαδρομές εγγραφών ανά γλώσσα που δεν εμφανίζονται πια ως χωριστές σελίδες αντιστοιχίζονται στους νέους συγκεντρωτικούς οδηγούς. Το `Documentation/OFFLINE_CURATION_MANIFEST.json` τεκμηριώνει τις αλλαγές. Δεν καταργήσαμε ανεξάρτητα χρήσιμα scripts και δεν επαναλάβαμε πρότυπες παραγράφους για να πιάσουμε κάποιο όριο μεγέθους. Η ιστοσελίδα, το Markdown και η offline αναζήτηση χρησιμοποιούν τα ίδια τελικά κείμενα.

## Κανόνες μελλοντικής συντήρησης

1. Η αντιστοιχία Ελληνικών–Αγγλικών ελέγχεται ανά πραγματικό θέμα και μονοπάτι, όχι με βάση τους αριθμούς των αρχικών IDs, επειδή αυτοί είχαν δημιουργηθεί με διαφορετική σειρά.
2. Κάθε νέα ενότητα πρέπει να δίνει συγκεκριμένη τεχνική εξήγηση, πραγματικό παράδειγμα, παραδοχές, ακραίο σενάριο και αναμενόμενο αποτέλεσμα. Δεν συμπληρώνουμε τεχνητά κείμενο και δεν ανακυκλώνουμε μεγάλες παραγράφους.
3. Τα δημοσιευμένα δεδομένα βρίσκονται στα `DedSec-Project-Website/data/en.js` και `el.js` και στις αντίστοιχες ενότητες του `Developer's Mind/Keep Programming Alive`. Το ZIP περιέχει ήδη τα αρχεία· δεν χρειάζεται άλλη ιδιωτική πηγή GitHub για να λειτουργεί.
4. Διατήρησε όσα `.py`, `.sh`, `.txt` ή άλλα παραδείγματα χρησιμοποιούνται. Αν μεταφέρεις οδηγό, ενημέρωσε τις ανακατευθύνσεις του manifest και διόρθωσε τα σχετικά links.
5. Μην τροποποιείς άδειες, στοιχεία ιδιοκτησίας, παραγωγικό domain ή κωδικούς. Ο Hacking Guide διατηρεί την προέλευση και τους περιορισμούς του.
6. Το αρχικό εργαλείο συγχώνευσης εκτελείται μία φορά. Σκόπιμα απαγορεύει δεύτερη εκτέλεση σε ήδη επιμελημένο αρχείο.

## Έλεγχοι χωρίς GitHub Actions

Από τον βασικό φάκελο εκτέλεσε `python3 scripts/audit_knowledge.py`, `python3 scripts/audit_knowledge_depth.py --strict`, `python3 scripts/audit_offline_links.py`, `python3 scripts/validate.py` και `python3 -m unittest discover -s scripts -p 'test_knowledge_*.py'`. Για την ιστοσελίδα, μπορείς να ανοίξεις τοπικό static server με `python3 -m http.server 8765 --bind 127.0.0.1` και να μεταβείς στο `/DedSec-Project-Website/index.html`. Στο Termux χρησιμοποιείς την διαθέσιμη Python και έναν τοπικό browser. Δεν απαιτείται online βάση δεδομένων. Προαιρετικά το `scripts/offline_browser_smoke.py` απαιτεί Chromium/Playwright και περιβάλλον που επιτρέπει τοπική πλοήγηση.

Δεν εκτελέστηκαν εξαντλητικά όλα τα παλιά ή εμπορικά runtimes ούτε έγινε ανεξάρτητη αξιολόγηση κάθε πρότασης.

## Παραγωγή ZIP και GitHub Actions

Το πακέτο είναι αυτοτελές. **Για τη δημιουργία του δεν χρησιμοποιήθηκε GitHub ούτε καταναλώθηκαν Actions minutes.** Αν το ανεβάσεις αργότερα στο Test, το workflow θα ελέγχει τα ήδη επιμελημένα δεδομένα, χωρίς γεννήτριες επαναλήψεων ή αυτόματες μαζικές διαγραφές. Επιτυχές deployment δεν αποτελεί από μόνο του απόδειξη ανεξάρτητης επιστημονικής αξιολόγησης.
