# Όρια εμπιστοσύνης browser σε static ιστοσελίδες

1. Ακόμα και μια static σελίδα απαιτεί έλεγχο URLs, φορμών και δεδομένων JavaScript.

2. Μην ενσωματώνεις μυστικά σε HTML ή JS· ό,τι φτάνει στον browser διαβάζεται.

3. Έλεγξε εξωτερικά links, scripts, πολιτικές περιεχομένου και αποθηκευμένες προτιμήσεις.

4. Θεώρησε URL fragments και εισαγόμενο κείμενο δεδομένα, όχι ασφαλές HTML.

5. Άσκηση: έλεγξε δική σου τοπική σελίδα για περιττές εξαρτήσεις και μη ασφαλή πλοήγηση.

**Όρια:** Μόνο για εκπαίδευση σε δικά σου ή ρητά εξουσιοδοτημένα συστήματα.
