# Έλεγξε άγνωστα scripts πριν τα εκτελέσεις

1. Αντιμετώπισε κατεβασμένο κώδικα ως μη έμπιστο ώσπου να ελέγξεις προέλευση και σκοπό.

2. Επιβεβαίωσε επίσημο maintainer, άδεια, dependencies και σημειώσεις έκδοσης.

3. Διάβασε τον κώδικα πριν από την εκτέλεση και βρες λήψεις, αλλαγές αρχείων και απαιτήσεις αδειών.

4. Όταν υπάρχει αξιόπιστο checksum, επαλήθευσε το κατεβασμένο αρχείο.

5. Άσκηση: ετοίμασε pre-run checklist για ασφαλές script του δικού σου repository.

**Όρια:** Μόνο για εκπαίδευση σε δικά σου ή ρητά εξουσιοδοτημένα συστήματα.
