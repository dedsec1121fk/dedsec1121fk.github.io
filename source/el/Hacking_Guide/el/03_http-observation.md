# Παρατήρηση HTTP με ασφάλεια από τον browser

1. Χρησιμοποίησε το Network του browser σε δοκιμαστική σελίδα που ελέγχεις.

2. Έλεγξε status, μέθοδο, τύπο περιεχομένου, ανακατευθύνσεις και cache.

3. Σύγκρινε αναμενόμενα και πραγματικά αιτήματα, εξωτερικές πηγές και cookies.

4. Χρησιμοποίησε δοκιμαστικά δεδομένα και μην δημοσιεύεις cookies ή κωδικούς.

5. Άσκηση: εξήγησε ένα επιτυχημένο τοπικό αίτημα και μια δοκιμαστική απάντηση 404.

**Όρια:** Μόνο για εκπαίδευση σε δικά σου ή ρητά εξουσιοδοτημένα συστήματα.
