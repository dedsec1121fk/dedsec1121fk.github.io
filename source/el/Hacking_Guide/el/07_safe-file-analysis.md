# Εξέτασε ύποπτα αρχεία χωρίς εκτέλεση

1. Μην τρέχεις άγνωστο εκτελέσιμο στο καθημερινό σου κινητό για να δεις τι κάνει.

2. Κατάγραψε όνομα, επέκταση, μέγεθος, πηγή και hash σε ξεχωριστές σημειώσεις.

3. Εξέτασε metadata και αναγνώσιμα headers με έμπιστα εργαλεία· μη θεωρείς ασφαλή τα ενσωματωμένα URLs.

4. Σύγκρινε ισχυρισμούς δημιουργού με επίσημες υπογεγραμμένες εκδόσεις.

5. Άσκηση: μελέτησε metadata ακίνδυνου αρχείου και εξήγησε τι δεν αποδεικνύουν.

**Όρια:** Μόνο για εκπαίδευση σε δικά σου ή ρητά εξουσιοδοτημένα συστήματα.
