# Τοπικός web server: bind addresses, θύρες και browser Android

## Αιτία και συμπτώματα
Μια υπηρεσία στο 127.0.0.1 είναι συνήθως διαθέσιμη μόνο από την ίδια συσκευή. Browser σε άλλη συσκευή δεν συνδέεται από το LAN IP του κινητού αν ο server δεν κάνει κατάλληλο bind και το δίκτυο δεν επιτρέπει κίνηση. Το URL πρέπει να περιλαμβάνει σωστή θύρα και πρωτόκολλο· ένας HTTP dev server δεν προσφέρει αυτόματα HTTPS.

## Αναπαραγωγή / διαγνωστικές εντολές
Εκτέλεσε σε δικό σου δοκιμαστικό περιβάλλον και έλεγξε τις διαδρομές πριν αλλάξεις αρχεία.
~~~sh
mkdir -p "$HOME/www-lab"
printf 'hello from Termux\n' > "$HOME/www-lab/index.html"
python -m http.server 8765 --bind 127.0.0.1 --directory "$HOME/www-lab"
# In another Termux session:
# curl -i http://127.0.0.1:8765/index.html
# Stop the demo server with Ctrl+C when finished.
~~~

## Επίλυση με βάση τα στοιχεία
Επιβεβαίωσε ότι τρέχει ο server και σε ποια διεύθυνση ακούει με ss -ltn όπου υπάρχει. Σύγκρινε 127.0.0.1, localhost και LAN IP· το IPv6 ::1 μπορεί να διαφέρει. Για πρόσβαση άλλης συσκευής προτίμησε ελεγχόμενη/κρυπτογραφημένη δημοσίευση και μόνο δοκιμαστικά δεδομένα. Μην εκθέτεις dev console χωρίς authentication στο 0.0.0.0.

## Πρακτικό εργαστήριο
Ζήτησε υπαρκτή και ανύπαρκτη σελίδα από το ίδιο κινητό, κατέγραψε 200 και 404 και έπειτα σταμάτα τον server για να δεις connection refused. Σύγκρινε με λανθασμένη χρήση HTTPS σε θύρα απλού HTTP.
