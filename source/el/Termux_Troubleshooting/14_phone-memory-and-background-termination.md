# Termux στο Android: τερματισμός στο background και πίεση μνήμης

## Γιατί συμβαίνει
Το Android μπορεί να τερματίσει διεργασίες στο background λόγω περιορισμών μπαταρίας, πίεσης μνήμης ή κύκλου ζωής εφαρμογών. Το Termux δεν εξαιρείται. Αν μια Python διεργασία εξαφανίζεται χωρίς traceback, μπορεί να την τερμάτισε το σύστημα και όχι ο κώδικας. Η συνολική RAM του κινητού δεν είναι διαθέσιμη ολόκληρη σε μία διεργασία.

## Ελεγχόμενες εντολές διάγνωσης

~~~sh
date
cat /proc/meminfo | head -n 8
ps -o pid,ppid,stat,rss,comm -p $$
df -h "$HOME"
# Before a long task, write checkpoints to a safe $HOME file.
# termux-wake-lock may keep CPU awake but cannot guarantee process survival.
~~~

## Ασφαλής πορεία διόρθωσης
Ξεχώρισε crash εφαρμογής, OOM, έλλειψη χώρου και περιορισμό μπαταρίας. Δες Android battery settings και επιτρεπόμενα logs. Χώρισε μεγάλες εργασίες σε στάδια με checkpoints: γράψε νέα κατάσταση σε προσωρινό αρχείο, ολοκλήρωσε τη γραφή και κάνε rename. Μείωσε μοντέλα, ταυτόχρονες εργασίες και peak RAM. Μη διατηρείς άσκοπα wake locks και μην απενεργοποιείς συνολικά προστασίες.

## Πρακτικό εργαστήριο
Τρέξε μικρό script που γράφει progress file ανά 100 συνθετικές εγγραφές, διέκοψέ το χειροκίνητα και συνέχισε από το τελευταίο checkpoint. Επιβεβαίωσε ότι δεν υπάρχουν διπλές εγγραφές και ότι μια μισοτελειωμένη εγγραφή δεν καταστρέφει το τελευταίο έγκυρο state. Μέτρα μνήμη χωρίς να προκαλέσεις πραγματικό OOM.
