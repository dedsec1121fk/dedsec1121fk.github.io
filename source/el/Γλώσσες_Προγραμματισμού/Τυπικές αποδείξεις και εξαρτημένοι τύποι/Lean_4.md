# lean_4 — συγκεντρωτικός οδηγός

## Lean 4

### Βασική ιδέα
Η Lean 4 συνδυάζει απόδειξη θεωρημάτων με functional προγραμματισμό μέσω typed expressions.

### Μικρό εκπαιδευτικό απόσπασμα
```text
def double (n : Nat) : Nat := n + n
#eval double 4
```

### Άσκηση βασισμένη στη συγκεκριμένη συμπεριφορά
Ξεχώρισε evaluation συνάρτησης από καθολική απόδειξη και κατέγραψε βήματα induction.

### Διάγνωση και όρια
Ένα επιτυχημένο παράδειγμα δεν αποδεικνύει θεώρημα για όλους τους φυσικούς αριθμούς.

Κάνε την άσκηση με πραγματικά δοκιμαστικά δεδομένα και με έκδοση Lean_4 που ταιριάζει στον κώδικα. Σημείωσε μία αρχική πρόβλεψη και την πραγματική έξοδο. Για περίπλοκο ή μη διαθέσιμο runtime, παρουσίασε τη στατική ανάλυση ως τέτοια, όχι ως επιτυχημένη εκτέλεση. Δοκίμασε ξεχωριστά την κανονική περίπτωση και μία οριακή τιμή, χωρίς πραγματικά προσωπικά ή παραγωγικά δεδομένα.

## Lean_4 — Αναλυτικός οδηγός εξάσκησης

### Μικρή αφετηρία πηγαίου κώδικα
~~~text
def greet (name : String) : String := "Hello, " ++ name ++ "!"
#eval greet "Ada"
~~~

**Περιβάλλον:** lean Hello.lean.. Κράτησε αντίγραφο του αρχικού κώδικα και σημείωσε έκδοση εργαλείου. Ξεχώρισε αν η εκτέλεση επιστρέφει τιμή, εμφανίζει κείμενο ή αλλάζει state. Για τις πρώτες δοκιμές χρησιμοποίησε απομονωμένο περιβάλλον, όχι πραγματικούς λογαριασμούς ή δεδομένα.

### Ανάλυση του ιδιαίτερου μηχανισμού
Απόδειξε απλή ισότητα με rfl και n + 0 = n για Nat με induction ή lemma. Εξέτασε ότι δεν έχεις sorry ή πρόσθετα axioms.

### Διάγνωση κρίσιμου ορίου
Lean 4 δεν είναι Lean 2/3· παλιά tutorials έχουν διαφορετικά keywords/tactics.
