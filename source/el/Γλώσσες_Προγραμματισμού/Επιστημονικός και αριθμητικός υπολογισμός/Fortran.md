# fortran — συγκεντρωτικός οδηγός

## Fortran

**Συνήθης χρήση:** Επιστημονικός και αριθμητικός υπολογισμός.

**Προτεινόμενη επέκταση αρχείου:** `.f90`.

**Εκτέλεση / περιβάλλον:** gfortran hello.f90 -o hello && ./hello.

### Αρχικό παράδειγμα

```
program hello
  implicit none
  character(len=*), parameter :: name = 'Ada'
  print *, 'Hello, ', name, '!'
end program hello
```

### Πώς διαβάζεται

Το implicit none εντοπίζει μη δηλωμένες μεταβλητές.

### Συνηθισμένο λάθος

Το implicit none εντοπίζει μη δηλωμένες μεταβλητές. Έλεγξε την έκδοση διερμηνευτή/μεταγλωττιστή και μην εκλαμβάνεις το δείγμα ως έτοιμη εφαρμογή παραγωγής.

## Fortran — Αναλυτικός οδηγός εξάσκησης

### Μικρή αφετηρία πηγαίου κώδικα
~~~text
program hello
  implicit none
  character(len=*), parameter :: name = 'Ada'
  print *, 'Hello, ', name, '!'
end program hello
~~~

**Περιβάλλον:** gfortran hello.f90 -o hello && ./hello.. Κράτησε αντίγραφο του αρχικού κώδικα και σημείωσε έκδοση εργαλείου. Ξεχώρισε αν η εκτέλεση επιστρέφει τιμή, εμφανίζει κείμενο ή αλλάζει state. Για τις πρώτες δοκιμές χρησιμοποίησε απομονωμένο περιβάλλον, όχι πραγματικούς λογαριασμούς ή δεδομένα.

### Ανάλυση του ιδιαίτερου μηχανισμού
Υλοποίησε pure συνάρτηση σε real(kind) arrays με interfaces, έλεγξε shapes και ενεργοποίησε bounds checking. Σύγκρινε array expression με DO loop.

### Διάγνωση κρίσιμου ορίου
Η default real precision χάνει ψηφία· οι πίνακες είναι column-major και το implicit none αποτρέπει κρυφά typos.

## Fortran — Παραδείγματα πραγματικού κώδικα

### Εκτέλεση των παραδειγμάτων

Τα παραδείγματα είναι μικρά και αυτοτελή. Χρησιμοποίησε τη σχετική εγκατεστημένη γλώσσα. Ενδεικτικά: `gfortran {file} -o demo && ./demo`. Μη συγχέεις τα ονόματα αρχείων με αυτόματη εγκατάσταση. Δούλεψε σε δοκιμαστικό φάκελο.
