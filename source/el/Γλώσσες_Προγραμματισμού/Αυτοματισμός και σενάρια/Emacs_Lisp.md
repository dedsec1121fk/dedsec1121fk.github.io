# emacs_lisp — συγκεντρωτικός οδηγός

## Emacs Lisp

### Μοντέλο λειτουργίας
Η Emacs Lisp είναι Lisp διάλεκτος μέσα στον editor Emacs με buffers, hooks και interactive commands.

### Παράδειγμα
```text
(+ 2 3)
(message "Sum: %d" (+ 2 3))
```

### Δοκίμασέ το με νόημα
Αξιολόγησε εκφράσεις στο scratch buffer και ξεχώρισε return value από μήνυμα στο echo area.

### Σφάλμα που πρέπει να ξεχωρίσεις
Οι buffer-local τιμές διαφέρουν από globals· δοκίμασε σε προσωρινό buffer.

Για να κρίνεις την άσκηση, κατέγραψε την αρχική είσοδο, την πρόβλεψη και την παρατήρηση σε πραγματικό, συμβατό περιβάλλον Emacs_Lisp. Δώσε ξεχωριστό παράδειγμα όπου αλλάζει μόνο μία μεταβλητή ή ένα όρισμα. Αν εργάζεσαι χωρίς την αναγκαία εφαρμογή, μελέτησε τη σύνταξη ως παράδειγμα και μην παρουσιάζεις το κείμενο ως εκτελεσμένο test.

## Emacs_Lisp — Αναλυτικός οδηγός εξάσκησης

### Πραγματικό αρχικό δείγμα
~~~text
(defun greet (name) (concat "Hello, " name "!"))
(princ (concat (greet "Ada") "\n"))
~~~

**Περιβάλλον:** emacs --batch -Q -l hello.el.. Επιβεβαίωσε ότι έχεις το σωστό compiler, host ή simulator πριν θεωρήσεις την έξοδο αξιόπιστη. Για scripts με πρόσβαση σε προσωπικά αρχεία ή ρυθμίσεις, χρησιμοποίησε προσωρινά και read-only δεδομένα.

### Συγκεκριμένος στόχος υλοποίησης
Όρισε interactive command που διαβάζει current buffer χωρίς αλλαγή. Σύγκρινε buffer-local variables με lexical-binding και δοκίμασε nil.

### Κρίσιμο λάθος που πρέπει να αναγνωρίζεις
Η αξιολόγηση σε λάθος buffer αλλάζει αποτέλεσμα· χρησιμοποίησε with-current-buffer και απόφυγε save-buffer χωρίς πρόθεση.

## Emacs_Lisp — Διαδρομή ουσιαστικής εξάσκησης

### Θεμελιώδης άσκηση
Όρισε interactive Emacs Lisp command που αναφέρει το μέγεθος current buffer χωρίς τροποποιήσεις.

### Άσκηση επίλυσης προβλήματος
Σύγκρινε lexical let state με buffer-local variable. Άνοιξε δύο buffers και παρατήρησε διαφορετικές τοπικές τιμές.

### Ανεξάρτητο έργο
Μετέτρεψε την εντολή σε μικρό minor mode, έλεγξε enable/disable και βεβαιώσου ότι δεν μένουν ανεπιθύμητα keybindings.
