# tcl — συγκεντρωτικός οδηγός

## Tcl

### Έννοια
Η Tcl εκτελεί commands· κενά χωρίζουν words, brackets εκτελούν εντολές και braces αναβάλλουν substitution.

### Παράδειγμα πηγαίου κώδικα ή χρήσης
```text
set a 3
puts [expr {$a * 4}]
```

### Άσκηση με συγκεκριμένο στόχο
Εξήγησε γιατί το expr βρίσκεται σε brackets και πώς τα braces προστατεύουν την έκφραση.

### Έλεγχος και διάγνωση
Η σύγχυση braces και quotes αλλάζει χρόνο αξιολόγησης· έλεγξε interpolation πριν εισαγάγεις εξωτερικές τιμές.

Σημείωσε την είσοδο, το αναμενόμενο αποτέλεσμα και το πραγματικό αποτέλεσμα στην εγκατεστημένη έκδοση της Tcl. Αν ο κώδικας δεν είναι προσβάσιμος από το κινητό, κράτησε το παράδειγμα ως μη δοκιμασμένο και εξήγησε τη σημασιολογία αντί να ισχυριστείς επιτυχία. Κάνε μια δεύτερη δοκιμή που απομονώνει μόνο τον μηχανισμό της άσκησης και κράτησε ακριβές σφάλμα με τρόπο που να μην εκθέτει προσωπικά δεδομένα.

## Tcl — Αναλυτικός οδηγός εξάσκησης

### Πραγματικό αρχικό δείγμα
~~~text
proc greet {name} { return "Hello, $name!" }
puts [greet Ada]
~~~

**Περιβάλλον:** tclsh hello.tcl.. Επιβεβαίωσε ότι έχεις το σωστό compiler, host ή simulator πριν θεωρήσεις την έξοδο αξιόπιστη. Για scripts με πρόσβαση σε προσωπικά αρχεία ή ρυθμίσεις, χρησιμοποίησε προσωρινά και read-only δεδομένα.

### Συγκεκριμένος στόχος υλοποίησης
Γράψε proc που διατρέχει Tcl list και δίνει άθροισμα. Σύγκρινε braced expressions με quoted strings και ασφαλή δημιουργία λίστας.

### Κρίσιμο λάθος που πρέπει να αναγνωρίζεις
Οι κανόνες Tcl διαφέρουν από shell· eval με user input εκτελεί κώδικα. Διατήρησε list semantics αντί split σε κενά.

## Tcl — Διαδρομή ουσιαστικής εξάσκησης

### Θεμελιώδης κατανόηση
Η Tcl αναλύει εντολές σε λέξεις: οι `{}` εμποδίζουν substitution, οι `[]` εκτελούν command substitution και τα εισαγωγικά ομαδοποιούν λέξεις με ενεργό substitution. Οι Tcl lists δεν είναι απλό κείμενο χωρισμένο στα κενά. Προτίμησε `foreach` και εντολές διαχείρισης λιστών. Έλεγξε τιμές με `string is integer -strict` πριν από το `incr`.

### Κώδικας προς δοκιμή
~~~tcl
proc sum_valid {items} {
    set total 0
    foreach item $items {
        if {![string is integer -strict $item]} { error "not integer" }
        incr total $item
    }
    return $total
}
if {[sum_valid {2 3 5}] != 10} { error "bad sum" }
if {![catch {sum_valid {2 invalid}} msg] || $msg ne "not integer"} {
    error "invalid input accepted"
}
puts "all checks passed"
~~~

### Εκτέλεση και ερμηνεία
Αποθήκευσε ως `sum.tcl` και τρέξε `tclsh sum.tcl`, με αναμενόμενη έξοδο `all checks passed`. Το `catch` επιτρέπει έλεγχο αναμενόμενης αποτυχίας, αλλά δεν πρέπει να κρύβει άλλα σφάλματα. Για API προτίμησε δομημένους κωδικούς αντί για κείμενο διαγνωστικών. Κατάγραψε `info patchlevel` για συμπεριφορές που εξαρτώνται από έκδοση.

### Πρακτική εργασία
Κατασκεύασε εγγραφή δύο πεδίων με `list`, με όνομα ομάδας που περιέχει κενά και ακέραιο σκορ. Διάτρεξε εγγραφές χωρίς να χαλάει η ομαδοποίηση. Όρισε κανόνα για αρνητικές τιμές και δοκίμασε κενή είσοδο, ένα στοιχείο, μη αριθμητικό κείμενο και μηδενικό σκορ. Σύγκρινε τα αποτελέσματα `catch`.
