## Algorithm

### Πώς συμπεριφέρεται η έννοια
Πεπερασμένη επαναλήψιμη διαδικασία από inputs σε outputs. Correctness, termination και πόροι είναι διαφορετικά ζητήματα· η κοντινότερη ορατή διαδρομή δεν είναι πάντα η συντομότερη συνολικά.

### Μικρό παράδειγμα
~~~text
def linear_find(items,x):
    for i,v in enumerate(items):
        if v==x: return i
    return None
assert linear_find([4,7],7)==1
~~~

### Πρακτική διερεύνηση
Έλεγξε κενό input, duplicates και missing. Εξήγησε γιατί η επιλογή πρώτου match είναι μέρος του contract.

### Δοκιμή ορίου
Για Αλγόριθμος, δοκίμασε δεύτερη είσοδο που αλλάζει το αποτέλεσμα. Σημείωσε αναμενόμενη συμπεριφορά πριν το run και εξήγησε τον κανόνα που παραβιάζεται.

## Abstraction

### Πώς συμπεριφέρεται η έννοια
Παρουσίαση ουσιωδών operations χωρίς έκθεση implementation details. File-like interface read/write μπορεί να στηρίζεται σε memory ή disk, εφόσον διατηρεί το ίδιο contract.

### Μικρό παράδειγμα
~~~text
from io import StringIO
stream=StringIO('abc')
assert stream.read(2)=='ab'
assert stream.read()=='c'
~~~

### Πρακτική διερεύνηση
Αντικατάστησε StringIO με προσωρινό text file. Βρες ποια συμπεριφορά πρέπει να παραμείνει ίδια και ποια μπορεί να διαφέρει.

### Δοκιμή ορίου
Για Αφαίρεση, δοκίμασε δεύτερη είσοδο που αλλάζει το αποτέλεσμα. Σημείωσε αναμενόμενη συμπεριφορά πριν το run και εξήγησε τον κανόνα που παραβιάζεται.

## API

### Πώς συμπεριφέρεται η έννοια
Συμβόλαιο μέσω του οποίου components ζητούν ενέργειες και λαμβάνουν αποτελέσματα. Περιλαμβάνει params, errors, authentication και compatibility, όχι μόνο URL endpoint.

### Μικρό παράδειγμα
~~~text
def create_task(title):
    if not isinstance(title,str) or not title.strip(): raise ValueError('title')
    return {'id':1,'title':title}
assert create_task('Read')['id']==1
~~~

### Πρακτική διερεύνηση
Όρισε response σε empty title και duplicate request. Ξεχώρισε client validation από server enforcement.
