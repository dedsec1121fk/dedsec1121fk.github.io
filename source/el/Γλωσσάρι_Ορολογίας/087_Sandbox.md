# Sandbox — άλλο πρόχειρος φάκελος, άλλο όριο ασφάλειας

## Τι σημαίνει
Sandbox είναι περιβάλλον που περιορίζει τι μπορεί να διαβάσει ή να αλλάξει μια διεργασία, π.χ. πρόσβαση σε αρχεία, δικαιώματα, system calls, δίκτυο και συσκευές. Ένας προσωρινός φάκελος, Python virtual environment, Git branch ή ιδιωτικό παράθυρο browser **δεν** αποτελεί από μόνο του απομόνωση για κακόβουλο κώδικα.

## Ασφαλές παράδειγμα οργάνωσης, όχι απομόνωσης
~~~python
from pathlib import Path
from tempfile import TemporaryDirectory

with TemporaryDirectory() as root:
    workspace = Path(root)
    file = workspace / "sample.txt"
    file.write_text("training data", encoding="utf-8")
    assert file.read_text(encoding="utf-8") == "training data"
~~~
Ο κώδικας καθαρίζει δεδομένα **έμπιστης** άσκησης. Η ίδια διεργασία Python μπορεί ακόμη να διαβάζει άλλα αρχεία του χρήστη με τα αντίστοιχα OS permissions. Μην εκτελείς άγνωστα binaries θεωρώντας ότι ο φάκελος σε προστατεύει.

## Σχεδιασμός πραγματικού ορίου
Σε offline προβολή μαθημάτων, προεπιλογή είναι απλή εμφάνιση κειμένου χωρίς εκτέλεση. Αν απαιτείται εκτέλεση, χρησιμοποίησε κατάλληλο OS sandbox ή VM, περιορισμένα writable mounts, μη προνομιούχο χρήστη, φραγμένο δίκτυο όπου δεν χρειάζεται, όρια μνήμης/CPU/χρόνου και κανένα μυστικό credential. Οι μηχανισμοί Android/Termux, desktop Linux και Windows **δεν** είναι ίδιοι.

## Δοκιμές ασφάλειας
1. Φτιάξε πίνακα αδειών: ο αναγνώστης μπορεί να βλέπει μαθήματα, όχι να γράφει εκτός επιτρεπτής περιοχής.
2. Σε δικό σου προσωρινό δοκιμαστικό περιβάλλον προσπάθησε αβλαβή εγγραφή σε προστατευμένο φάκελο. Περίμενε άρνηση.
3. Με απενεργοποιημένο δίκτυο επιβεβαίωσε ότι δεν υπάρχει πρόσβαση σε επιλεγμένη τοπική δοκιμαστική υπηρεσία.
4. Έλεγξε αν timeout διακόπτει εργασία και τι συμβαίνει στα child processes.
5. Βεβαιώσου ότι logs και exceptions δεν εμφανίζουν μυστικά.

## Αποδείξεις
Κατάγραψε μηχανισμό απομόνωσης, έκδοση OS, δικαιώματα και επιτυχημένα/απορριφθέντα tests. Το TemporaryDirectory προσφέρει καθαρισμό, όχι sandbox.
