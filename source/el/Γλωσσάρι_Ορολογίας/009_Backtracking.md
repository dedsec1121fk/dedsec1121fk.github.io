# Γλωσσάρι: backtracking και πολυπλοκότητα αναζήτησης

## Backtracking

### Πώς συμπεριφέρεται η έννοια
Search που δοκιμάζει υποψήφια λύση, απορρίπτει παραβίαση και επαναφέρει state για άλλο branch. Χρήσιμο σε Sudoku/permutations, αλλά μπορεί να έχει εκθετικό κόστος.

### Μικρό παράδειγμα
~~~text
def choices(xs):
    if not xs: yield []
    else:
        for i,x in enumerate(xs):
            for tail in choices(xs[:i]+xs[i+1:]): yield [x]+tail
assert len(list(choices([1,2,3])))==6
~~~

### Πρακτική διερεύνηση
Πρόσθεσε constraint που απορρίπτει prefix και μέτρησε branches που παραλείπονται.

## Big O

### Μικρό παράδειγμα

def contains(items,x):

~~~

## Binary search — ορισμός

### Πώς συμπεριφέρεται η έννοια
Search σε sorted data με υποδιπλασιασμό διαστήματος ανά βήμα. Έχει O(log N) comparisons· unsorted data παραβιάζουν την προϋπόθεση.

### Μικρό παράδειγμα
~~~text
def find(a,x):
    lo,hi=0,len(a)
    while lo<hi:
        m=(lo+hi)//2
        if a[m]<x: lo=m+1
        else: hi=m
    return lo if lo<len(a) and a[lo]==x else None
assert find([1,3,5],3)==1
~~~

### Πρακτική διερεύνηση
Παρακολούθησε lo/hi/m σε missing number· δοκίμασε duplicates και empty array σε σύγκριση με bisect_left.

## Bit

### Πώς συμπεριφέρεται η έννοια

## Boolean

### Πώς συμπεριφέρεται η έννοια
Λογική true/false για conditions. Στην Python το bool είναι subclass του int, οπότε isinstance(True,int) είναι True· αυστηρό numeric validation ίσως χρειάζεται type(x) is int.

### Μικρό παράδειγμα
~~~text
assert (2<3) is True
assert isinstance(True,int)
assert type(True) is bool
~~~

### Πρακτική διερεύνηση
