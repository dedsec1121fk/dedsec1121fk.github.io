Jsonnet

Έννοια

Η Jsonnet είναι γλώσσα παραγωγής JSON με object composition και υπολογιζόμενα πεδία.

Παράδειγμα πηγαίου κώδικα ή χρήσης

local base = { port: 8080 };
base + { host: '127.0.0.1' }

Άσκηση με συγκεκριμένο στόχο

Παρήγαγε το object και έλεγξε τους τύπους των πεδίων. Πρόσθεσε object με ίδια key για να μελετήσεις το merge.

Έλεγχος και διάγνωση

Η παραγωγή config δεν εγγυάται επιχειρησιακή εγκυρότητα· χρησιμοποίησε schema και έλεγξε overrides.

Σημείωσε την είσοδο, το αναμενόμενο αποτέλεσμα και το πραγματικό αποτέλεσμα στην εγκατεστημένη έκδοση της Jsonnet. Αν ο κώδικας δεν είναι προσβάσιμος από το κινητό, κράτησε το παράδειγμα ως μη δοκιμασμένο και εξήγησε τη σημασιολογία αντί να ισχυριστείς επιτυχία. Κάνε μια δεύτερη δοκιμή που απομονώνει μόνο τον μηχανισμό της άσκησης και κράτησε ακριβές σφάλμα με τρόπο που να μην εκθέτει προσωπικά δεδομένα.

Jsonnet — Αναλυτικός οδηγός εξάσκησης

Ξεκίνησε από αληθινή σύνταξη

Το αρχικό παράδειγμα της Jsonnet είναι η μικρότερη αφετηρία. Διάβασε τη σειρά των πράξεων και τον τρόπο εμφάνισης, έπειτα επιβεβαίωσέ το στο σωστό περιβάλλον. Μην θεωρείς ότι η σύνταξη άλλης γλώσσας έχει ίδια σημασία.

local name = 'Ada';
{ greeting: 'Hello, ' + name + '!' }

Περιβάλλον εκτέλεσης: jsonnet hello.jsonnet.. Έλεγξε έκδοση compiler/interpreter πριν τροποποιήσεις τον κώδικα και κράτησε την αρχική έξοδο. Δούλεψε σε προσωρινό κατάλογο, μακριά από πραγματικά δεδομένα.

Οδηγούμενο εργαστήριο

Δημιούργησε base configuration με δύο overlays. Σύγκρινε το παραγόμενο JSON και επικύρωσε ports στην εφαρμογή· η παραγωγή δεν σημαίνει σωστό schema.

Δοκιμές ορίων

Το object merge με + δεν είναι πάντοτε αναδρομικό. Δοκίμασε nested fields και μελέτησε inheritance πριν θεωρήσεις ότι διατηρούνται.

Προχωρημένη αποστολή

Φτιάξε ξεχωριστό αρχείο για το παραπάνω εργαστήριο και πειραματίσου με μία αλλαγή σε σειρά, σχήμα, τύπο, scope ή περιβάλλον, ανάλογα με τη Jsonnet. Καθόρισε invariant και σύγκρινε αναμενόμενη με πραγματική έξοδο. Αν κάτι διαφέρει, απομόνωσε το ελάχιστο παράδειγμα πριν μεγαλώσεις το πρόγραμμα.
