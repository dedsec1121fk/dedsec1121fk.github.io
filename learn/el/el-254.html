Squirrel

Βασική ιδέα

Η Squirrel είναι embeddable scripting γλώσσα με tables, closures και class-like objects.

Μικρό εκπαιδευτικό απόσπασμα

local values = [2, 4, 6];
::print(values.len());

Άσκηση βασισμένη στη συγκεκριμένη συμπεριφορά

Ξεχώρισε μήκος array από table lookup σε συμβατό Squirrel VM.

Διάγνωση και όρια

Ο host επιλέγει διαθέσιμα globals· η print δεν παρέχεται απαραίτητα από κάθε embedding.

Κάνε την άσκηση με πραγματικά δοκιμαστικά δεδομένα και με έκδοση Squirrel που ταιριάζει στον κώδικα. Σημείωσε μία αρχική πρόβλεψη και την πραγματική έξοδο. Για περίπλοκο ή μη διαθέσιμο runtime, παρουσίασε τη στατική ανάλυση ως τέτοια, όχι ως επιτυχημένη εκτέλεση. Δοκίμασε ξεχωριστά την κανονική περίπτωση και μία οριακή τιμή, χωρίς πραγματικά προσωπικά ή παραγωγικά δεδομένα.

Squirrel — Αναλυτικός οδηγός εξάσκησης

Πραγματικό αρχικό δείγμα

function greet(name) { return "Hello, " + name + "!"; }
print(greet("Ada") + "\n");

Περιβάλλον: Run with a Squirrel interpreter.. Επιβεβαίωσε ότι έχεις το σωστό compiler, host ή simulator πριν θεωρήσεις την έξοδο αξιόπιστη. Για scripts με πρόσβαση σε προσωπικά αρχεία ή ρυθμίσεις, χρησιμοποίησε προσωρινά και read-only δεδομένα.

Συγκεκριμένος στόχος υλοποίησης

Φτιάξε table με optional key, έλεγξε παρουσία πριν indexing και μοντελοποίησε state machine με ρητές μεταβάσεις. Δοκίμασε λάθος τύπους.

Κρίσιμο λάθος που πρέπει να αναγνωρίζεις

Η Squirrel ενσωματώνεται σε host και διαθέσιμα globals/μνήμη διαφέρουν. Missing table slot δεν είναι ασφαλής default.

Squirrel — Διαδρομή ουσιαστικής εξάσκησης

Κατανόηση πραγματικού execution model

Φτιάξε table με health και score παίκτη και έλεγξε optional slot χωρίς να θεωρείς δεδομένη την ύπαρξη.

Ελεγχόμενη αποτυχία και διόρθωση

Σχεδίασε state machine menu, active, paused. Μη επιτρεπτά transitions να δίνουν σαφές error.

Ανεξάρτητη πρακτική εργασία

Τρέξε toy simulation με δύο event sequences και διαφορετικό τελικό state. Κατάγραψε τα globals που παρέχει πραγματικά το host runtime.
