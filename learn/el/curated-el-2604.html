ClassNotFoundException

Γλώσσα / περιβάλλον: Java

Τι σημαίνει

Η απαιτούμενη κλάση δεν βρίσκεται κατά την εκτέλεση.

Πώς διορθώνεται

Έλεγξε πακέτο, classpath και εγκατεστημένα αρχεία.

NoClassDefFoundError

Γλώσσα / περιβάλλον: Java

Τι σημαίνει

Μία κλάση λείπει ή απέτυχε να αρχικοποιηθεί στην εκτέλεση.

Πώς διορθώνεται

Έλεγξε εξαρτήσεις, εκδόσεις και προγενέστερη εξαίρεση.

Ποια κλάση δεν βρίσκει η JVM;

Η ClassNotFoundException εμφανίζεται συχνά όταν ο κώδικας ζητά συγκεκριμένη κλάση από class loader και αυτή δεν εντοπίζεται. Η NoClassDefFoundError μπορεί να εμφανιστεί όταν κλάση που ήταν διαθέσιμη στη μεταγλώττιση απουσιάζει κατά την εκτέλεση ή όταν η αρχικοποίησή της απέτυχε προηγουμένως. Δεν αρκεί να κατεβάσουμε τυχαία άλλο JAR επειδή οι ονομασίες των δύο εξαιρέσεων μοιάζουν.

public class Demo {
    public static void main(String[] args) {
        System.out.println("Classpath test");
    }
}

Σε προσωρινό δοκιμαστικό φάκελο μεταγλώττισε το Demo.java με την έκδοση Java που έχεις. Σύγκρινε την εκτέλεση όταν το classpath περιλαμβάνει τον φάκελο του Demo.class και όταν δείχνει σε άλλη διαδρομή. Κατάγραψε το πλήρες όνομα της κλάσης και έλεγξε αν κάποια δήλωση package αλλάζει τη θέση του αρχείου. Σε σύγχρονο Java project μην συγχέεις το module path με το classpath.

Απουσία κλάσης ή αποτυχία αρχικοποίησης;

Αν η κλάση υπάρχει αλλά σφάλει μέσα σε static initializer, η πρώτη εξαίρεση μπορεί να διαφέρει από τις επόμενες προσπάθειες χρήσης της ίδιας κλάσης. Φύλαξε όλη την αλυσίδα αιτιών και το πρώτο σχετικό σφάλμα, όχι μόνο την τελευταία γραμμή NoClassDefFoundError. Έλεγξε dependency lockfile, build configuration και αξιόπιστη προέλευση αρχείων· απόφυγε άγνωστα JAR από τυχαία αποτελέσματα αναζήτησης.

Στοιχεία επαλήθευσης

Χρειάζονται έκδοση JVM, build tool, το ακριβές όνομα κλάσης, περιεχόμενα του archive και classpath/module path. Αν μία διόρθωση packaging βοηθήσει, επιβεβαίωσε ότι εκτελέστηκε ξανά το ίδιο πρόγραμμα με το διορθωμένο περιβάλλον.
