Dhall

Τι προσφέρει η γλώσσα

Η Dhall είναι γλώσσα ρυθμίσεων με ισχυρούς τύπους και normalization. Στοχεύει σε αναπαραγώγιμες τιμές και όχι σε ανεξέλεγκτα scripts.

Μικρό παράδειγμα προς μελέτη

{ name = "example", retryCount = 3, enabled = True }

Άλλαξε το retryCount σε συμβολοσειρά και εξήγησε πώς αλλάζει ο τύπος του record. Έλεγξε το με συγκεκριμένο schema.

Τι να επαληθεύσεις

Κατάγραψε την πραγματική έκδοση εργαλείου, τις απαιτούμενες εξαρτήσεις και την έξοδο σε δοκιμαστικά δεδομένα για τη Dhall. Πρόβλεψε το αποτέλεσμα πριν το ελέγξεις και διατήρησε την αρχική και τη διορθωμένη εκδοχή ώστε να φαίνεται η αιτιώδης διαφορά. Μην αποκαλείς ένα απόσπασμα εκτελεσμένο αν δεν έχεις το κατάλληλο περιβάλλον.

Παγίδα ειδική για το θέμα

Χειρίσου συνειδητά τα remote imports και τους ελέγχους hash· ο τύπος δεν εγγυάται αξιοπιστία πηγής.

Εργαστήριο εξάσκησης: Dhall

Η Dhall περιγράφει τιμές ρυθμίσεων με στατικούς τύπους· δεν είναι σενάριο shell ούτε γενική προστακτική γλώσσα. Διάβασε το κύριο μάθημα Dhall. Ο στόχος είναι να απορρίπτονται ασύμβατες ρυθμίσεις κατά τον έλεγχο τύπων, όχι αφού προκαλέσουν πρόβλημα στην εφαρμογή.

Δήλωσε ακριβή δομή δεδομένων

Αποθήκευσε ως config.dhall:

let Config = { name : Text, retryCount : Natural, enabled : Bool }
let instance : Config = { name = "example", retryCount = 3, enabled = True }
in instance

Με διαθέσιμο CLI έλεγξε dhall type --file config.dhall και στη συνέχεια dhall --file config.dhall. Εξήγησε τη διαφορά ανάμεσα στον τύπο εγγραφής, στην πραγματική τιμή και στη δήλωση : Config. Το 0 παραμένει Natural, αλλά το "three" και ένας αρνητικός αριθμός δεν έχουν τον απαιτούμενο τύπο. Κράτησε τα πραγματικά μηνύματα σφάλματος για κάθε τροποποίηση.

Δομή, κανονικοποίηση και τοπικές εισαγωγές

Πρόσθεσε πεδίο region = "eu" στην τιμή χωρίς να το δηλώσεις στον τύπο Config. Διερεύνησε πώς ο ακριβής τύπος εντοπίζει άγνωστα πεδία. Έπειτα σύγκρινε την αρχική έκφραση 1 + 2 με το κανονικοποιημένο αποτέλεσμα της Dhall: ο υπολογισμός δεν ισοδυναμεί με αντικατάσταση κειμένου. Δημιούργησε τοπικό αρχείο defaults.dhall με επιτρεπτή τιμή και εισήγαγέ το με ./defaults.dhall. Αφαίρεσε προσωρινά το αρχείο και παρατήρησε το σφάλμα εισαγωγής. Δεν χρειάζεται σύνδεση στο διαδίκτυο.

Ασφάλεια και αναπαραγωγιμότητα

Ο σωστός τύπος δεν εγγυάται την αξιοπιστία της πηγής. Αν μία πραγματική εφαρμογή επιτρέπει απομακρυσμένες εισαγωγές, χρειάζεται πολιτική για hashes εξαρτήσεων, κλείδωμα εκδόσεων και offline λειτουργία. Ξεχώρισε την αρχική αναπαράσταση από την κανονικοποιημένη τιμή. Η εξαγωγή JSON απαιτεί ξεχωριστό έλεγχο συμβατότητας με το πρόγραμμα που θα το διαβάσει.

Παραδοτέα: έκδοση Dhall, επιτυχημένος έλεγχος τύπου, τρία σφάλματα από λάθος τιμή/πεδίο/εισαγωγή και ένα αποτέλεσμα κανονικοποίησης. Χωρίς Dhall δήλωσε μη εκτελεσμένες δοκιμές.
