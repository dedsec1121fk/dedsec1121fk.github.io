Processing (Java mode)

Μοντέλο λειτουργίας

Η Java mode του Processing χρησιμοποιεί sketch callbacks για σχέδιο, animation και χειρισμό εισόδου.

Παράδειγμα

void setup() { size(300, 200); }
void draw() { background(20); ellipse(150,100,50,50); }

Δοκίμασέ το με νόημα

Άλλαξε την x συντεταγμένη σε mouseX και παρατήρησε πώς επανεκτελείται το draw().

Σφάλμα που πρέπει να ξεχωρίσεις

Το background σε κάθε frame σβήνει παλιά σχέδια· διατήρησε state αν θέλεις ίχνος.

Για να κρίνεις την άσκηση, κατέγραψε την αρχική είσοδο, την πρόβλεψη και την παρατήρηση σε πραγματικό, συμβατό περιβάλλον Processing_Java_mode. Δώσε ξεχωριστό παράδειγμα όπου αλλάζει μόνο μία μεταβλητή ή ένα όρισμα. Αν εργάζεσαι χωρίς την αναγκαία εφαρμογή, μελέτησε τη σύνταξη ως παράδειγμα και μην παρουσιάζεις το κείμενο ως εκτελεσμένο test.

Processing_Java_mode — Αναλυτικός οδηγός εξάσκησης

Ξεκίνησε από αληθινή σύνταξη

Το αρχικό παράδειγμα της Processing Java mode είναι η μικρότερη αφετηρία. Διάβασε τη σειρά των πράξεων και τον τρόπο εμφάνισης, έπειτα επιβεβαίωσέ το στο σωστό περιβάλλον. Μην θεωρείς ότι η σύνταξη άλλης γλώσσας έχει ίδια σημασία.

void setup() {
  println("Hello, Ada!");
  exit();
}

Περιβάλλον εκτέλεσης: Run from Processing IDE (Java mode).. Έλεγξε έκδοση compiler/interpreter πριν τροποποιήσεις τον κώδικα και κράτησε την αρχική έξοδο. Δούλεψε σε προσωρινό κατάλογο, μακριά από πραγματικά δεδομένα.

Οδηγούμενο εργαστήριο

Κίνησε κύκλο σε καμβά 400x240. Άλλαξε από x += 1 ανά draw() σε κίνηση βάσει millis(), δοκίμασε pause/resume και αναπήδηση που λαμβάνει υπόψη την ακτίνα.

Δοκιμές ορίων

Το background καθορίζει αν αφήνεται ίχνος και το frameRate είναι στόχος, όχι εγγύηση. Το Android mode είναι ξεχωριστό.

Προχωρημένη αποστολή

Φτιάξε ξεχωριστό αρχείο για το παραπάνω εργαστήριο και πειραματίσου με μία αλλαγή σε σειρά, σχήμα, τύπο, scope ή περιβάλλον, ανάλογα με τη Processing Java mode. Καθόρισε invariant και σύγκρινε αναμενόμενη με πραγματική έξοδο. Αν κάτι διαφέρει, απομόνωσε το ελάχιστο παράδειγμα πριν μεγαλώσεις το πρόγραμμα.

Processing_Java_mode — Διαδρομή ουσιαστικής εξάσκησης

Πρακτικές εργασίες

  1. Άλλαξε ντετερμινιστικό seed και πρόβλεψε την αλλαγή αποτελέσματος.
  2. Χώρισε συντεταγμένες, παραμέτρους χρώματος και ενημέρωση κατάστασης.
  3. Χρησιμοποίησε το κατάλληλο περιβάλλον εκτέλεσης για το παράδειγμα.

Ερωτήσεις ουσίας

  • Τι υπολογίζεται μία φορά και τι σε κάθε καρέ;
  • Ποια εργαλεία εκτελούν ή ελέγχουν το παράδειγμα και σε ποια έκδοση;
  • Ποιο είναι το μικρότερο ελεγμένο πρόγραμμα; Ποιες είναι οι παρενέργειες;
  • Πώς γίνεται διάκριση μεταξύ σφάλματος σύνταξης, λογικής και περιβάλλοντος;
  • Πώς δοκιμάζονται άκυρα δεδομένα χωρίς βλάβη σε αρχεία ή σύστημα;
