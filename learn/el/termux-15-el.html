Αιτία και συμπτώματα

Η εγκατάσταση πακέτων μπορεί να αποτύχει όταν γεμίσει ο ιδιωτικός χώρος της εφαρμογής, το filesystem προορισμού ή ο προσωρινός χώρος build. Ένα pip wheel build ίσως χρειάζεται πολύ περισσότερα προσωρινά MB από το τελικό πακέτο. Γεμάτο filesystem μπορεί να αφήσει ημιτελή downloads· στόχος είναι να ελευθερώσεις χώρο χωρίς απώλεια projects ή credentials.

Αναπαραγωγή / διαγνωστικές εντολές

Εκτέλεσε σε δικό σου δοκιμαστικό περιβάλλον και έλεγξε τις διαδρομές πριν αλλάξεις αρχεία.

df -h "$HOME"
du -sh "$HOME" 2>/dev/null
python -m pip cache dir
python -m pip cache info
# Review candidates before any deletion.
# If appropriate after review: python -m pip cache purge

Επίλυση με βάση τα στοιχεία

Μέτρησε ποιο filesystem γέμισε και πού γράφει προσωρινά το pip. Διαχώρισε caches από repositories, βάσεις και ιδιωτικές ρυθμίσεις. Οι εντολές pkg clean και pip cache purge μπορούν να ελευθερώσουν caches όπου υποστηρίζονται, αλλά επιβεβαίωσε τι σβήνουν. Απόφυγε γενικά rm -rf ή διαγραφή του $PREFIX. Κράτα requirements και backup ώστε να μπορείς να ξαναχτίσεις το περιβάλλον.

Πρακτικό εργαστήριο

Φτιάξε μικρό αναλώσιμο φάκελο αρχείων και μέτρησέ τον με du. Διέγραψε μόνο τον συγκεκριμένο φάκελο και έλεγξε τη μεταβολή. Σε ελεγχόμενο pip download κατέγραψε ελεύθερο χώρο πριν/μετά και εξήγησε τη διαφορά cache, εγκατεστημένου πακέτου και peak προσωρινών αρχείων.
