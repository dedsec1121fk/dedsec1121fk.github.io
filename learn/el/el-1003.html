CS0246 — Δεν αναγνωρίζεται τύπος ή namespace

Περιβάλλον: μεταγλώττιση C# και επίλυση τύπων/χώρων ονομάτων.

Τι λείπει πραγματικά

Το CS0246 αφορά τύπο ή namespace, όχι απαραίτητα απλή τοπική μεταβλητή όπως συχνά το CS0103. Μπορεί να λείπει ένα using, αναφορά σε άλλο project ή package, να υπάρχει διαφορετική γραφή, ασυμβατό target framework ή μη προσβάσιμος τύπος.

Ελεγχόμενο παράδειγμα

Σε project χωρίς implicit/global import για System.Collections.Generic, η δήλωση αποτυγχάνει:

using System;
// List<int> values = new(); // CS0246 χωρίς το κατάλληλο import

Η σωστή έκδοση είναι:

using System.Collections.Generic;
List<int> values = new() { 2, 4, 6 };
System.Console.WriteLine(values.Count);

Εναλλακτικά χρησιμοποίησε System.Collections.Generic.List<int>. Έξοδος: 3. Σε σύγχρονο template τα implicit global usings ίσως έχουν ήδη εισαγάγει αυτόν τον χώρο ονομάτων· δοκίμασε με απενεργοποιημένη τη δυνατότητα για βέβαιη αναπαραγωγή.

Η διαφορά import και dependency

Το using δεν εγκαθιστά βιβλιοθήκη. Αν λείπει εξωτερικός τύπος, εξέτασε .csproj, PackageReference / ProjectReference, target framework και εκτέλεσε dotnet restore όταν πρόκειται για dependencies. Για δικό σου τύπο έλεγξε την πραγματική δήλωση namespace και την ορατότητα (public) μεταξύ projects.

Σειρά αντιμετώπισης

  1. Διάβασε το πρώτο μήνυμα CS0246 και κατέγραψε το ακριβές όνομα.
  2. Δοκίμασε το πλήρως προσδιορισμένο όνομα για να ξεχωρίσεις missing import από missing assembly.
  3. Έλεγξε ορθογραφία και κεφαλαία/πεζά του namespace.
  4. Έλεγξε αναφορές έργων, package restore, SDK και target framework.
  5. Κάνε rebuild μετά τη σωστή αλλαγή, όχι τυχαία εγκατάσταση πακέτων με παρόμοιο όνομα.

Οριακή περίπτωση

Αν το List<int> λειτουργεί χωρίς using, δες πρώτα ImplicitUsings και τα global usings. Η ίδια γραμμή κώδικα μπορεί να μεταγλωττίζεται διαφορετικά σε δύο projects.
