Ένα APK που έγινε build μπορεί να μην εγκαθίσταται στο κινητό

Έλεγξε τις απαιτήσεις εγκατάστασης

Το min SDK, η αρχιτεκτονική, το package ID, η σχέση υπογραφής με ήδη εγκατεστημένη έκδοση και ο ελεύθερος χώρος μπορούν να επηρεάσουν την εγκατάσταση. Νεότερο APK με ίδιο ID μπορεί να απορριφθεί αν υπογράφηκε με άλλο κλειδί ή αν το versionCode δεν ακολουθεί τους κανόνες ενημέρωσης. Επιτυχία σε emulator δεν αποδεικνύει ότι το πρόγραμμα λειτουργεί σωστά στο πραγματικό τηλέφωνο.

# Μόνο με Android SDK platform-tools/build-tools:
adb devices
adb shell getprop ro.build.version.sdk
adb shell getprop ro.product.cpu.abi
apksigner verify --verbose app-release.apk

Απόφυγε καταστροφικές «διορθώσεις»

Μην αλλάζεις τυχαία package name ή signing key μόνο και μόνο για να εγκατασταθεί update: μπορεί να χαθεί πρόσβαση στα παλιά δεδομένα. Πριν από uninstall έλεγξε backup και έγκριση του χρήστη. Σε install error κράτησε το ακριβές μήνυμα και αναζήτησε αν αφορά υπογραφή, συμβατότητα ή storage.

Δοκίμασε την πραγματική χρήση

Φτιάξε πίνακα ελέγχων για touch controls, pause/resume, περιστροφή, offline launch, permissions αρχείων και ενημέρωση υπάρχουσας εγκατάστασης. Σε γραφικά ή παιχνίδια μέτρησε frame pacing και καθυστέρηση input στη συσκευή, όχι μόνο desktop FPS. Έλεγξε text scaling και προσανατολισμούς οθόνης που υποστηρίζεις.

Στοιχεία παράδοσης

Κράτησε ID, min/target SDK, SHA-256 APK, αποτέλεσμα ελέγχου υπογραφής, ABI και Android version. Πράσινο build και επιτυχής εγκατάσταση αποτελούν μόνο δύο βήματα· χρειάζεται χωριστός έλεγχος λειτουργιών εφαρμογής.
