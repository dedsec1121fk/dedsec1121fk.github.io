GLSL — Αναλυτικός οδηγός εξάσκησης

Πραγματικό αρχικό δείγμα

#version 330 core
out vec4 FragColor;
void main() { FragColor = vec4(0.2, 0.5, 0.8, 1.0); }

Περιβάλλον: Compile as a fragment shader in a supported graphics host.. Επιβεβαίωσε ότι έχεις το σωστό compiler, host ή simulator πριν θεωρήσεις την έξοδο αξιόπιστη. Για scripts με πρόσβαση σε προσωπικά αρχεία ή ρυθμίσεις, χρησιμοποίησε προσωρινά και read-only δεδομένα.

Συγκεκριμένος στόχος υλοποίησης

Υλοποίησε fragment gradient από normalized UV και clamp χρώματος. Σύγκρινε linear color με sRGB display και δοκίμασε UV στα όρια.

GLSL — Διαδρομή ουσιαστικής εξάσκησης

Στόχος και περιβάλλον

Δημιούργησε σε desktop OpenGL 3.3 ένα fragment shader με χρωματική διαβάθμιση και κύκλο με μαλακή ακμή. Χρησιμοποιούμε GLSL 330 core, όχι έτοιμο κώδικα για OpenGL ES: εκεί απαιτούνται άλλη έκδοση και κατάλληλοι κανόνες precision. Το πρόγραμμα-ξενιστής πρέπει να συνδέει vertex stage που παρέχει το interpolated v_uv.

Κώδικας (circle.frag)

#version 330 core
in vec2 v_uv;
out vec4 fragColor;
uniform float u_radius;

void main() {
    vec2 uv = clamp(v_uv, vec2(0.0), vec2(1.0));
    float distanceFromCenter = length(uv - vec2(0.5));
    float circle = 1.0 - smoothstep(
        u_radius - 0.01, u_radius + 0.01, distanceFromCenter
    );
    vec3 background = vec3(uv.x, uv.y, 0.2);
    fragColor = vec4(mix(background, vec3(1.0, 0.9, 0.2), circle), 1.0);
}

Το v_uv είναι παρεμβαλλόμενη συντεταγμένη επιφάνειας, όχι θέση pixel. Το clamp μετατρέπει τιμές UV εκτός [0,1] σε άκρα, αντί για επανάληψη υφής. Η ζώνη του smoothstep έχει πλάτος 0.02 μονάδες UV και όχι σταθερά pixels. Η μετατροπή linear/sRGB εξαρτάται από το render target και την εφαρμογή, όχι από αυτόν τον κώδικα.

Δοκιμές και εντοπισμός αιτίας

  1. Με u_radius=0.25, στο UV (0.5,0.5) ο κύκλος έχει πλήρη ένταση, ενώ στα (0,0) και (1,1) μηδενική.
  2. Στο (0.75,0.5) η ένταση της ακμής αναμένεται περίπου 0.5.
  3. Χρησιμοποίησε μη τετράγωνο viewport· αν ο κύκλος παραμορφώνεται, χρειάζεται διόρθωση αναλογίας αξόνων.
  4. Άλλαξε σκόπιμα το όνομα εξόδου στο vertex shader και κράτησε το σφάλμα σύνδεσης, όχι μόνο μεταγλώττισης fragment.
  5. Έλεγξε ξεχωριστά συσκευή OpenGL ES: η έκδοση 330 core δεν σημαίνει ότι υποστηρίζεται σε Android.

Απόδειξη ολοκλήρωσης

Κράτησε το ζεύγος vertex/fragment, πραγματική έκδοση OpenGL context, logs compilation/link, εικόνες και ρυθμίσεις χρώματος του host. Χωρίς πραγματικό GL περιβάλλον, το παράδειγμα αποτελεί στατική μελέτη και όχι επιβεβαιωμένο GPU test.
