Stan

Έννοια

Η Stan περιγράφει πιθανοτικά μοντέλα με κατανομές και δεδομένα συγκεκριμένων τύπων· η δειγματοληψία γίνεται από ξεχωριστούς αλγορίθμους.

Παράδειγμα πηγαίου κώδικα ή χρήσης

parameters { real mu; }
model { mu ~ normal(0, 1); }

Άσκηση με συγκεκριμένο στόχο

Δήλωσε πρώτα τις διαστάσεις δεδομένων. Ξεχώρισε prior από posterior αντί να θεωρείς κάθε δείγμα ανεξάρτητη μέτρηση.

Έλεγχος και διάγνωση

Το μοντέλο μπορεί να μεταγλωττίζεται αλλά να έχει divergences ή προβλήματα ταυτοποίησης· εξέτασε τα sampler diagnostics.

Σημείωσε την είσοδο, το αναμενόμενο αποτέλεσμα και το πραγματικό αποτέλεσμα στην εγκατεστημένη έκδοση της Stan. Αν ο κώδικας δεν είναι προσβάσιμος από το κινητό, κράτησε το παράδειγμα ως μη δοκιμασμένο και εξήγησε τη σημασιολογία αντί να ισχυριστείς επιτυχία. Κάνε μια δεύτερη δοκιμή που απομονώνει μόνο τον μηχανισμό της άσκησης και κράτησε ακριβές σφάλμα με τρόπο που να μην εκθέτει προσωπικά δεδομένα.

Πρακτική συνέχεια

Διαμόρφωσε άλλο παράδειγμα με αλλαγή σε ένα μόνο βήμα. Περιέγραψε γιατί το αποτέλεσμα είναι διαφορετικό και αν η διαφορά οφείλεται στη σύνταξη, στο σύστημα εκτέλεσης ή σε εξωτερικό εργαλείο. Μην επεκτείνεις το έργο σε μη εξουσιοδοτημένα συστήματα.

Εργαστήριο εξάσκησης: Stan

Δεδομένα, παράμετροι και κατανομή

Η Stan περιγράφει στατιστικό μοντέλο και όχι γενικό script εκτύπωσης αριθμών. Σε αρχείο mean.stan:

data {
  int<lower=1> N;
  array[N] real y;
}
parameters {
  real mu;
}
model {
  mu ~ normal(0, 5);
  y ~ normal(mu, 1);
}
generated quantities {
  real y_rep = normal_rng(mu, 1);
}

Για δοκιμή όρισε N = 3 και y = [1.0, 1.2, 0.8] μέσω CmdStan ή άλλου συμβατού host. Η mu έχει prior και οι παρατηρήσεις likelihood. Η y_rep είναι τυχαία παραγόμενη τιμή, όχι υποχρεωτικά ο δειγματικός μέσος. Δεν αποδίδουμε φανταστικές αριθμητικές εξόδους posterior.

Compilation και δειγματοληψία

Μεταγλώττισε πρώτα το μοντέλο και έπειτα τρέξε sampling με καταγεγραμμένο seed, warm-up και αριθμό δειγμάτων. Το επιτυχημένο compile δεν αποδεικνύει σύγκλιση αλυσίδων ούτε ποιότητα συμπερασμάτων. Εξέτασε διαθέσιμα diagnostics όπως R-hat και divergences, χωρίς να τα παραλείπεις από τον έλεγχο.

Διαφορετικά λάθη εισόδου

Δώσε N=3 αλλά μόνο δύο στοιχεία y και έπειτα N=0. Η πρώτη περίπτωση παραβιάζει το μήκος πίνακα, η δεύτερη τον περιορισμό lower=1. Πρόκειται για σφάλματα ορίων δεδομένων, όχι απόδειξη ότι η κανονική κατανομή δεν έχει νόημα. Κατέγραψε σε ποιο στάδιο απορρίπτεται κάθε fixture.

Αυτόνομη μελέτη

Αντικατάστησε τη σταθερή διασπορά των παρατηρήσεων με θετική άγνωστη παράμετρο και δικαιολόγησε κατάλληλο prior. Εξήγησε την αβεβαιότητα εκτίμησης με μόνο τρεις μετρήσεις. Σύγκρινε predictive draws με σταθερά seeds χωρίς να ταυτίζεις διαφορετικά δείγματα. Αναφορά: https://mc-stan.org/docs/

Stan — Διαδρομή ουσιαστικής εξάσκησης

Πρακτικές εργασίες

  1. Έλεγξε διαστάσεις και μονάδες ενός αριθμητικού μοντέλου.
  2. Σύγκρινε με μικρό παράδειγμα γνωστής αναλυτικής λύσης.
  3. Κατάγραψε κριτήρια σύγκλισης και ανοχές όπου χρειάζεται προσέγγιση.

Ερωτήσεις ουσίας

  • Ποιο αριθμητικό σφάλμα ή λάθος μονάδας αλλάζει το αποτέλεσμα;
  • Ποια εργαλεία εκτελούν ή ελέγχουν το παράδειγμα και σε ποια έκδοση;
  • Ποιο είναι το μικρότερο ελεγμένο πρόγραμμα; Ποιες είναι οι παρενέργειες;
  • Πώς γίνεται διάκριση μεταξύ σφάλματος σύνταξης, λογικής και περιβάλλοντος;
  • Πώς δοκιμάζονται άκυρα δεδομένα χωρίς βλάβη σε αρχεία ή σύστημα;
