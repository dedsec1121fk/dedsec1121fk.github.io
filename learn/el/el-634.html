Οι κβαντικές γλώσσες απαιτούν εξειδικευμένους προσομοιωτές. Έλεγξε την έκδοση διερμηνευτή/μεταγλωττιστή και μην εκλαμβάνεις το δείγμα ως έτοιμη εφαρμογή παραγωγής.

Q_Sharp — Αναλυτικός οδηγός εξάσκησης

Μικρή αφετηρία πηγαίου κώδικα

namespace Hello {
    open Microsoft.Quantum.Diagnostics;
    @EntryPoint()
    operation Main() : Unit {
        Message("Hello, Ada!");
    }
}

Περιβάλλον: Use a Q#-enabled project and simulator.. Κράτησε αντίγραφο του αρχικού κώδικα και σημείωσε έκδοση εργαλείου. Ξεχώρισε αν η εκτέλεση επιστρέφει τιμή, εμφανίζει κείμενο ή αλλάζει state. Για τις πρώτες δοκιμές χρησιμοποίησε απομονωμένο περιβάλλον, όχι πραγματικούς λογαριασμούς ή δεδομένα.

Ανάλυση του ιδιαίτερου μηχανισμού

Δέσμευσε qubit, εφάρμοσε H, μέτρησε, κάνε reset και επανάλαβε με συγκεκριμένο πλήθος shots. Σύγκρινε με την θεωρητική πιθανότητα 50/50.

Διάγνωση κρίσιμου ορίου

Μία μέτρηση δεν αποδεικνύει κατανομή. Simulator και hardware target έχουν διαφορετικά gates/diagnostics.

Q_Sharp — Διαδρομή ουσιαστικής εξάσκησης

Πρακτικές εργασίες

  1. Φτιάξε κύκλωμα δύο καταστάσεων με δοκιμή μέτρησης σε προσομοιωτή.
  2. Εξήγησε πώς διαφέρει η μέτρηση υπέρθεσης από ανάγνωση κλασικής μεταβλητής.
  3. Τεκμηρίωσε πύλες, qubits και εξαρτήσεις προσομοιωτή.

Ερωτήσεις ουσίας

  • Ποιες πράξεις είναι κλασικές και ποιες κβαντικές;
  • Ποια εργαλεία εκτελούν ή ελέγχουν το παράδειγμα και σε ποια έκδοση;
  • Ποιο είναι το μικρότερο ελεγμένο πρόγραμμα; Ποιες είναι οι παρενέργειες;
  • Πώς γίνεται διάκριση μεταξύ σφάλματος σύνταξης, λογικής και περιβάλλοντος;
