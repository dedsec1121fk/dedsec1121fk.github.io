Observe HTTP safely using browser tools

  1. Use the Network panel on a test page you control to observe one request.

  2. Check status code, request method, response content type, redirect chain and caching.

  3. Compare expected and actual network requests, including third-party resources and cookies.

  4. Use synthetic data for errors; never paste live session cookies or passwords into public reports.

  5. Exercise: capture and explain a successful local request and a deliberate 404 response.

Scope: Education and testing on owned or explicitly authorized systems only.
