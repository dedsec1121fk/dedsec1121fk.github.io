DedSec Project

Guide For Installation

Step-by-step instructions to install and set up the DedSec Project on Termux for Android, Ubuntu, Kali Linux, or Linux Mint.

Requirements

  • Supported system: Termux on Android, Ubuntu, Kali Linux, or Linux Mint.
  • Storage: Minimum 6GB free space for the DedSec Project installation.
  • RAM: Minimum 2GB.
  • Internet: Required for the first installation and for updates.

Storage warning: The 6GB requirement covers the DedSec Project installation itself. Scripts that capture or save additional content—such as photos, screenshots, videos, recordings, logs, downloads, or other generated files—can require extra storage beyond the 6GB project requirement.

Installation time: A complete installation can take approximately 20–50 minutes, depending on your internet connection and your device's processor.

Termux (Android)

Install Termux & Add-Ons

To install APKs such as F-Droid, enable installation from unknown apps for your browser or file manager in Android settings.

1. Install F-Droid

F-Droid is the recommended source for Termux and its add-ons.

Download F-Droid

How To Install The F-Droid APK

  1. Download the F-Droid APK from the link above.
  2. Open Android Settings, then Security or Apps & Notifications.
  3. Allow your browser or file manager to install unknown apps.
  4. Open the downloaded APK and tap Install.
  5. Open F-Droid and install Termux.

2. Install Termux Add-Ons

For the full Android feature set, install Termux and the supported add-ons from F-Droid.

Termux Termux:API Termux:Styling

3. Update Termux & Install Git

pkg update -y && pkg upgrade -y && pkg install git nano -y && termux-setup-storage

4. Clone DedSec

git clone https://github.com/dedsec1121fk/DedSec

5. Install DedSec

cd DedSec && bash Setup.sh

6. Launch DedSec Later

cd ~/DedSec && ./Run.sh

Termux tip: for long operations, long-press the terminal, open More, and enable Keep screen on. You can also use More → Style to customize the terminal.

After the first setup in Termux, choose your prompt, menu style and language, then run Save DedSec Project so a backup package is created. You can quickly open the English or Greek menu later by typing e or g.

Ubuntu

Install DedSec On Ubuntu

Open Terminal and run the following commands in order.

1. Install Requirements

sudo apt update && sudo apt install -y git python3 python3-venv python3-pip

2. Clone DedSec

git clone https://github.com/dedsec1121fk/DedSec

3. Run Setup

cd DedSec && bash Setup.sh

4. Launch DedSec Later

cd ~/DedSec && ./Run.sh

On Ubuntu, Setup.sh creates and uses the project-local .venv so the distro-managed Python installation is not replaced.
