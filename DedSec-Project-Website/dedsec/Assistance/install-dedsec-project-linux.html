Quick Summary

Install DedSec on Ubuntu, Kali Linux, or Linux Mint using the shared cross-platform installer and launcher.

Requirements

Use a user account with sudo access and a working internet connection. DedSec supports Ubuntu, Kali Linux, and Linux Mint through the same desktop setup.

Install Git

sudo apt update
sudo apt install -y git

Clone And Setup

git clone https://github.com/dedsec1121fk/DedSec
cd DedSec
bash Setup.sh

The setup installs desktop dependencies, creates .venv, and prepares Compat/bin.

Launch

./Run.sh

Use this launcher for normal desktop runs so the local environment and compatibility layer are applied.

Paths

Project Python lives in DedSec/.venv/. Compatibility commands live in DedSec/Compat/bin/. Tool outputs normally use ~/Downloads/ or the user's XDG Downloads directory.

Next Steps

For platform-specific save paths, use Learn About The Tools. For other setup or runtime problems, return to Assistance.
