Γρήγορη Περίληψη

Κατανόησε το Linux environment και τα file locations που χρησιμοποιεί το DedSec ώστε να κάνεις troubleshooting χωρίς λάθος αλλαγές.

Project Environment

Το desktop Linux χρησιμοποιεί τοπικό .venv μέσα στο DedSec repository. Τρέξε ./Run.sh αντί να αναμειγνύεις global Python packages με το project.

Έλεγχος Environment

cd ~/DedSec
pwd
./.venv/bin/python --version
printf "%s\n" "$PATH"

Compatibility Layer

Το Compat/bin παρέχει desktop-safe replacements ή shims για commands που περιμένουν portable scripts. Το Run.sh το προσθέτει αυτόματα.

Downloads

Τα portable εργαλεία συνήθως αποθηκεύουν στο ~/Downloads/ σε Ubuntu, Kali Linux και Linux Mint. Τα ακριβή paths ανά εργαλείο βρίσκονται στη σελίδα Μάθε Για Τα Εργαλεία.

Shell Files

Ubuntu και Linux Mint συνήθως χρησιμοποιούν ~/.bashrc. Το Kali μπορεί να χρησιμοποιεί ~/.zshrc. Το Termux χρησιμοποιεί $PREFIX/etc/bash.bashrc.

Επόμενα Βήματα

Για platform-specific save paths, δες τη σελίδα Μάθε Για Τα Εργαλεία. Για γενικά προβλήματα, επέστρεψε στη Βοήθεια.
