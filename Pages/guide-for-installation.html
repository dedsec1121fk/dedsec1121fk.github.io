Guide For Installation

Install the same DedSec Project on Termux for Android, Ubuntu, Kali Linux, or Linux Mint using the shared cross-platform setup and launcher.

Supported Systems

Termux on Android

Uses native Termux Python and packages. Android storage and Termux:API features remain available where the required Android permissions and add-ons are installed.

Ubuntu

Uses apt packages plus a project-local .venv. The launcher adds Compat/bin so portable DedSec tools use the desktop compatibility layer.

Kali Linux

Uses the same desktop setup with Bash or Zsh support, a local .venv, and Linux-aware Downloads paths.

Linux Mint

Uses the same Ubuntu-family setup: apt dependencies, local .venv, Compat/bin, and the user's desktop Downloads directory.

Before You Start

  • Keep a working internet connection available for the first setup.
  • On Termux, install Termux from F-Droid and run termux-setup-storage if you want Android Downloads access.
  • On Ubuntu, Kali Linux, and Linux Mint, use an account that can run sudo apt.
  • The desktop build creates its own .venv; do not install the project's Python packages globally.

1. Prepare Your System

Termux

pkg update -y && pkg upgrade -y
pkg install git nano -y
termux-setup-storage

Ubuntu / Kali Linux / Linux Mint

sudo apt update
sudo apt install -y git

2. Clone And Install DedSec

These commands are the same on all four supported systems:

git clone https://github.com/dedsec1121fk/DedSec
cd DedSec
bash Setup.sh

Setup.sh automatically detects Termux versus desktop Linux. On Termux it delegates to the native Termux installer. On Ubuntu, Kali Linux, and Linux Mint it installs the required apt packages, creates .venv, and prepares the compatibility layer.

3. Launch DedSec

./Run.sh

Use ./Run.sh after setup on every supported system. On desktop Linux it activates the project environment and compatibility commands automatically.

Updates

cd ~/DedSec
git pull
bash Setup.sh --update-only
./Run.sh

If you cloned DedSec somewhere other than ~/DedSec, change the first command to your actual project path.

Paths And Platform Differences

  • Termux Downloads: normally ~/storage/downloads/ / Android Download storage.
  • Desktop Linux Downloads: normally ~/Downloads/, including XDG-customized Downloads directories when the tool supports them.
  • Desktop Python: DedSec/.venv/.
  • Desktop compatibility commands: DedSec/Compat/bin/.
  • Shell startup files: Termux uses $PREFIX/etc/bash.bashrc; Ubuntu/Linux Mint commonly use ~/.bashrc; Kali may use ~/.zshrc.

Android App Launcher, Mobile Desktop, Termux Backup/Restore, Termux Repair Wizard, and Mobile Developer Setup are Termux-only. Linux shows those Android-specific utilities as not applicable instead of applying Android changes to the desktop system.
