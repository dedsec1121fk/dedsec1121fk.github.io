Frequently Asked Questions

Answers to real questions about DedSec Project, its programs, installation, Smartphone Academy, safety, compatibility, updates, repositories, contributions and support.

Project Basics

What Is The DedSec Project?

DedSec Project is a phone-first Termux toolkit and website ecosystem for learning, organizing scripts, checking links/files, exploring OSINT awareness, and solving Android/Termux workflow problems in a legal and responsible way.

Who Created It?

DedSec Project was created by Loukas Floros. The About The Founder page explains how an interest in Watch Dogs, technology, privacy, Termux, and programming developed into the project.

Is DedSec Project Only For Programmers?

No. It is designed for people who want to learn Termux and solve real digital problems from an Android phone. Beginners should start from the Installation Guide, then Learn About The Tools, then Assistance.

Does It Require Root?

Most of the project is built for no-root Android usage through Termux. If a tool ever needs a special permission, it should explain it before use.

Tools, Safety & Use

Are The Tools Meant For Illegal Hacking?

No. The project should be used for learning, privacy awareness, authorized testing, diagnostics, and personal workflow improvement. Do not use any tool against systems or accounts you do not own or have permission to test.

Where Can I Learn What Each Tool Does?

Open Learn About The Tools. That page explains the tools and helps you decide what to run before you touch Termux commands.

What Is ButSystem.py?

ButSystem.py is a local-first, self-hosted workspace included free inside DedSec Project. It is not a paid Store product; open its dedicated page to review its features, access model, and safeguards.

Installation And Compatibility

Which Termux Version Should I Use?

Use a current official Termux release from F-Droid or the project’s official GitHub releases. The old Google Play build is outdated and can cause repository or package problems.

Will DedSec Project Work Without Root?

Most DedSec Project scripts and the Smartphone Academy are designed for normal, non-rooted Android devices. Features that depend on protected Android areas, raw wireless interfaces or system-level modification may be unavailable without root.

Why Does A Package Or Python Module Fail To Install?

Common causes are an outdated Termux build, unfinished package upgrades, unsupported CPU wheels, low storage, broken repositories or a dependency that needs compilation. Use Assistance and include the complete error, Android version, architecture and command you ran.

Can I Use The Project On A Low-End Phone?

Yes for many scripts, lessons and local utilities. Large AI models, media processing, heavy scans and multiple servers can be slow or run out of memory. Start with lightweight options and keep free storage available.

Does The Installer Download Missing Requirements Automatically?

Many launchers check for common packages and Python modules, but not every Android, repository or compiler problem can be solved automatically. Read each prompt before accepting changes and keep a backup of personal modifications.

Can The Project Be Used Offline?

Downloaded local scripts, documentation and many Academy exercises can work offline. Features that query websites, APIs, repositories, maps, weather, public records or remote services require a connection.

Programs And Components

What Is Settings.py?

Settings.py is the central control panel for the DedSec Project and the launcher for DedSec OS. It manages updates, packages/modules, backups and offline transfer, Sponsors-Only access, prompt/GitHub/usage settings, HTTP Proxy & Tor utilities, menu style, auto-start and language; DedSec OS adds a browser-native desktop with movable/resizable windows, Start/taskbar/Action Center, File Explorer and shared Open/Save dialogs, Notepad, Word/Excel/PowerPoint/PDF tools, photo/video/media apps, Terminal, Software Center, personalization, login/optional 2FA/recovery, and Help & Troubleshooting with guided fixes and live diagnostics.

What Is Developer Base?

Developer Base groups phone-first utilities for files, coding, project structure, local websites, notes and development workflows inside Termux.

What Do File Converter.py And File Type Checker.py Do?

File Type Checker helps inspect the real type of a file instead of trusting only its extension. File Converter provides guided conversion workflows where supported. Always preserve originals before converting.

What Is Mobile Developer Setup.py?

Mobile Developer Setup.py builds a complete Termux developer workstation instead of only installing a few packages. It installs multiple language runtimes, compilers and build tools, databases, npm/Python developer utilities, Zsh/Oh My Zsh with Powerlevel10k, Termux UI settings and NvChad, and includes backup, update, repair, restore and uninstall workflows. Exact package availability can still depend on Android/Termux architecture and upstream repositories.

What Are The Network Tools For?

They support defensive learning, local diagnostics, link checks, QR creation, footprint awareness and authorized network observation. They are not permission to scan or interfere with systems you do not own.

What Is Personal Information Capture?

It is a high-risk training category demonstrating how social engineering and browser permission requests can expose data. Use it only in controlled demonstrations with explicit informed consent. Never deploy deceptive pages against real people.

What Are The Games Inside The Project?

The Games section contains local terminal and browser experiments such as Pet Friends, Tamagotchi, Terminal Arcade and other interactive projects. They demonstrate scripting, state, menus and creative coding on Android.

What Is ButSystem.py?

ButSystem.py is an exclusive local-first communication and social platform experiment with chats, groups, stories, profiles, files, security controls and temporary sharing links. Read its dedicated page before installing or resetting it.

Smartphone Academy

Is Smartphone Academy Only A Website?

The website teaches the theory and gives structured instructions. Practical work runs locally through Termux and the included Smartphone-Academy.py companion, which prepares safe workspaces and records progress on the device.

Where Is Academy Progress Stored?

Progress is stored locally under ~/.dedsec-smartphone-academy in the Termux home directory. It is not tied to a website account and is not uploaded automatically.

Do The Practical Labs Touch My Real Files?

The companion creates separate training folders with supplied samples. A lesson may ask you to inspect your own phone settings, but it should clearly say so. Never point destructive commands at shared storage or personal folders.

Are Repair And Custom ROM Lessons Step-By-Step Flashing Instructions?

No universal procedure is safe for every model. The Academy teaches model verification, documentation research, backups, risk assessment, dry runs and rollback planning. Follow the exact manufacturer or ROM maintainer guide for your exact model and region.

Can I Complete The Academy Without Internet?

Many downloaded theory pages and local labs work offline. Research lessons, official-source verification, package installation and update checks require temporary internet access.

How Do I Resume A Practical Lab?

Run python Smartphone-Academy.py status to view progress, then open the existing workspace under ~/.dedsec-smartphone-academy/workspaces. Do not use --force unless you have backed up the current work.

Can A Lesson Estimate Take Longer Or Less Time?

Yes. Hours are estimates for active setup, testing, verification and documentation. Device speed, experience, troubleshooting and the depth of your evidence can change the real duration.

Security, Privacy And Legal Boundaries

Does The Website Collect Information About Visitors?

The site may use Google Tag Manager and analytics for visits, clicks, device information and approximate region-level statistics, as explained in the Privacy Policy. The local Academy progress file is separate and stays on the device.

Does DedSec Project Secretly Upload My Files?

The public project should be reviewed like any other source code. Do not enter secrets into scripts you have not inspected. Network-enabled tools should state why they connect, and you should test them with non-sensitive samples first.

Can I Use Fake Pages Or Capture Tools On Another Person?

Only with explicit informed consent in a controlled training environment. Deception, credential collection, camera or microphone capture and location collection without authorization can be illegal and harmful.

Does An Antivirus Warning Automatically Mean A Script Is Malware?

Not automatically, especially for security tools, local servers or obfuscated samples, but warnings must not be ignored. Inspect the source, permissions, network behavior and files changed before deciding whether to run it.

What Should Happen If A Contributor Faces Legal Action?

Their rights, access to legal counsel, presumption of innocence and due process should be respected. Public discussion should rely on verified records and must not obstruct investigations, threaten people or assume guilt from headlines.

Repositories, Updates And Contributions

What Is The Difference Between The Main And Backup Websites?

The main website is ded-sec.space. The backup at ded-sec.online is intended for continuity if the main domain or hosting path becomes unavailable. Repository-aware builds keep their domain and path rules separate.

Which Repository Contains The Main Website Source?

The main website repository is dedsec1121fk/dedsec1121fk.github.io. The sal-scar/ded-sec repository is the backup mirror, while dedsec1121fk/test is used to review changes before production.

How Do I Update An Existing DedSec Project Installation?

Follow the Update guide in Assistance or the repository README. Back up changed settings, personal data and custom scripts before pulling or replacing files, because project updates may change filenames or structure.

Will An Update Overwrite My Modifications?

It can if you replace the full project folder. Keep personal changes in a separate branch or backup, compare changes with Git and merge intentionally instead of copying blindly.

Where Should I Report A Bug?

Use the project’s Contact page or the relevant GitHub repository issue tracker. Include the exact script, commit or version, Android version, Termux source, architecture, complete command and complete error output with secrets removed.

Can I Contribute Code, Translations Or Testing?

Yes. Small focused pull requests are easier to review. Explain what changed, how it was tested in Termux, which files are affected and any safety or compatibility limitations.

Why Does The Test Repository Have Different Links?

GitHub project pages run below /, while the main and backup domains run at the root. The repository-aware build rewrites internal paths, canonical URLs, CNAME and indexing files for the selected target.
