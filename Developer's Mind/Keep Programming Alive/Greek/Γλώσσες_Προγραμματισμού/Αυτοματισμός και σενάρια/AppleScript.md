# applescript — συγκεντρωτικός οδηγός

## AppleScript

### Βασική ιδέα
Η AppleScript αυτοματοποιεί εφαρμογές macOS μέσω scripting dictionaries και events.

### Μικρό εκπαιδευτικό απόσπασμα
```text
set total to 2 + 3
return total
```

### Άσκηση βασισμένη στη συγκεκριμένη συμπεριφορά
Στον Script Editor σύγκρινε απλό αριθμητικό script με tell block προς επιτρεπόμενη εφαρμογή.

### Διάγνωση και όρια
Τα permissions για automation και accessibility δεν είναι δεδομένα· μη ζητάς άσκοπα δικαιώματα.

Κάνε την άσκηση με πραγματικά δοκιμαστικά δεδομένα και με έκδοση AppleScript που ταιριάζει στον κώδικα. Σημείωσε μία αρχική πρόβλεψη και την πραγματική έξοδο. Για περίπλοκο ή μη διαθέσιμο runtime, παρουσίασε τη στατική ανάλυση ως τέτοια, όχι ως επιτυχημένη εκτέλεση. Δοκίμασε ξεχωριστά την κανονική περίπτωση και μία οριακή τιμή, χωρίς πραγματικά προσωπικά ή παραγωγικά δεδομένα.

## AppleScript — Αναλυτικός οδηγός εξάσκησης

### Πραγματικό αρχικό δείγμα
~~~text
set nameText to "Ada"
return "Hello, " & nameText & "!"
~~~

**Περιβάλλον:** osascript hello.applescript on macOS.. Επιβεβαίωσε ότι έχεις το σωστό compiler, host ή simulator πριν θεωρήσεις την έξοδο αξιόπιστη. Για scripts με πρόσβαση σε προσωπικά αρχεία ή ρυθμίσεις, χρησιμοποίησε προσωρινά και read-only δεδομένα.

### Συγκεκριμένος στόχος υλοποίησης
Αυτοματοποίησε ανάγνωση metadata επιλογής Finder χωρίς μετακίνηση/διαγραφή. Σύγκρινε tell application με Standard Additions και δοκίμασε κενή επιλογή.

### Κρίσιμο λάθος που πρέπει να αναγνωρίζεις
Τα application dictionaries αλλάζουν και οι άδειες αυτοματισμού απαιτούν έγκριση. Μην υποθέτεις frontmost-app context.

## AppleScript — Διαδρομή ουσιαστικής εξάσκησης

### Θεμελιώδης άσκηση
Χρησιμοποίησε tell application Finder για ανάγνωση metadata επιλεγμένου αρχείου χωρίς αλλαγές. Εξήγησε τις άδειες Apple events.

### Άσκηση επίλυσης προβλήματος
Χειρίσου άδεια επιλογή και πολλά αρχεία, εμφανίζοντας μόνο filenames. Έλεγξε το scripting dictionary της εφαρμογής.

### Ανεξάρτητο έργο
Φτιάξε automation με ρητή επιβεβαίωση πριν αλλάξεις προσωρινή σημείωση. Επανέφερε το αρχικό και κατέγραψε τα macOS privacy permissions.
