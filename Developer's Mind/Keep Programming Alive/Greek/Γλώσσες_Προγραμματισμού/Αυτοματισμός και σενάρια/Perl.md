# perl — συγκεντρωτικός οδηγός

## Perl

### Μοντέλο λειτουργίας
Η Perl ξεχωρίζει scalar, array και hash contexts και έχει ισχυρή επεξεργασία κειμένου· το context μπορεί να αλλάξει αποτέλεσμα.

### Παράδειγμα
```text
my @values = (1, 2, 3);
print scalar(@values), "\n";
```

### Δοκίμασέ το με νόημα
Εξήγησε γιατί scalar(@values) δίνει πλήθος στοιχείων και σύγκρινέ το με join.

### Σφάλμα που πρέπει να ξεχωρίσεις
Οι regular expressions χρειάζονται σαφείς παραδοχές· ένα match δεν σημαίνει πλήρες validation.

Για να κρίνεις την άσκηση, κατέγραψε την αρχική είσοδο, την πρόβλεψη και την παρατήρηση σε πραγματικό, συμβατό περιβάλλον Perl. Δώσε ξεχωριστό παράδειγμα όπου αλλάζει μόνο μία μεταβλητή ή ένα όρισμα. Αν εργάζεσαι χωρίς την αναγκαία εφαρμογή, μελέτησε τη σύνταξη ως παράδειγμα και μην παρουσιάζεις το κείμενο ως εκτελεσμένο test.

## Perl — Αναλυτικός οδηγός εξάσκησης

### Πραγματικό αρχικό δείγμα
~~~text
use strict;
use warnings;
sub greet { my ($name) = @_; return "Hello, $name!"; }
print greet("Ada"), "\n";
~~~

**Περιβάλλον:** perl hello.pl.. Επιβεβαίωσε ότι έχεις το σωστό compiler, host ή simulator πριν θεωρήσεις την έξοδο αξιόπιστη. Για scripts με πρόσβαση σε προσωπικά αρχεία ή ρυθμίσεις, χρησιμοποίησε προσωρινά και read-only δεδομένα.

### Συγκεκριμένος στόχος υλοποίησης
Διάβασε UTF-8 με lexical filehandle, μέτρησε regex matches και χειρίσου αποτυχία open(). Σύγκρινε captures με noncapturing groups.

### Κρίσιμο λάθος που πρέπει να αναγνωρίζεις
Στην Perl scalar/list context αλλάζει αποτέλεσμα· δήλωσε encoding. Μην φορτώνεις τεράστια αρχεία ή εκτελείς untrusted input.

## Perl — Παραδείγματα πραγματικού κώδικα

### Εκτέλεση των παραδειγμάτων

Τα παραδείγματα είναι μικρά και αυτοτελή. Χρησιμοποίησε τη σχετική εγκατεστημένη γλώσσα. Ενδεικτικά: `perl {file}`. Μη συγχέεις τα ονόματα αρχείων με αυτόματη εγκατάσταση. Δούλεψε σε δοκιμαστικό φάκελο.


## Perl — Διαδρομή ουσιαστικής εξάσκησης

### Θεμελιώδης κατανόηση
Το `use strict` επιβάλλει ρητές δηλώσεις μεταβλητών και το `use warnings` αποκαλύπτει ύποπτες πράξεις. Ένα hash μετρά εμφανίσεις αποτελεσματικά, όμως η σειρά διάσχισης δεν είναι σταθερή για εμφάνιση. Ταξινόμησε τα keys πριν από την έξοδο. Μη χρησιμοποιείς `eval` για να αναλύεις κείμενο χρήστη. Ξεχώρισε parsing και καταμέτρηση και όρισε κανόνα για κενά και πεζά/κεφαλαία.

### Κώδικας προς δοκιμή
~~~perl
use strict;
use warnings;
my @words = qw(alpha beta alpha);
my %counts;
for my $word (@words) { $counts{$word}++ }
for my $word (sort keys %counts) {
    print "$word\t$counts{$word}\n";
}
die "bad count\n" unless $counts{alpha} == 2 && $counts{beta} == 1;
~~~

### Εκτέλεση και ερμηνεία
Αποθήκευσε ως `counts.pl`. Τρέξε `perl -c counts.pl` για σύνταξη και μετά `perl counts.pl` για συμπεριφορά. Περίμενε `alpha<TAB>2`, `beta<TAB>1` με αυτήν τη σειρά και επιτυχημένο exit. Ένα λάθος όνομα μεταβλητής με `strict` πρέπει να εντοπίζεται νωρίς. Ο συντακτικός έλεγχος δεν αποδεικνύει ότι οι καταμετρήσεις είναι σωστές.

### Πρακτική εργασία
Διάβασε λέξεις από STDIN αντί για σταθερό πίνακα. Όρισε συμπεριφορά για κενές γραμμές, κράτησε διαφορετικά τα `Alpha` και `alpha` και αποφάσισε αν αφαιρείται trailing whitespace. Έλεγξε κενή είσοδο, επαναλήψεις και διαφορετική σειρά εγγραφών. Η ταξινόμηση των keys επιτρέπει σταθερό golden-file test.

## Perl — Τεχνικά σημεία και συχνές παγίδες

### Τεχνική γνώση

1. Scalars, arrays και hashes έχουν διαφορετικά sigils και συμπεριφορά ανά context.
2. Το regex δεν είναι γενικός parser για κάθε εμφώλευση.
3. Σε συντηρήσιμο Perl κώδικα ενεργοποίησε strict και warnings και έλεγξε την είσοδο.
