# Διάγνωση αρχείων που λείπουν και Python modules

## No such file or directory

**Γλώσσα / περιβάλλον:** Shell / Linux

### Τι σημαίνει
Δεν επιλύεται διαδρομή αρχείου ή φακέλου.

### Πώς διορθώνεται
Έλεγξε εισαγωγικά, τρέχοντα φάκελο, πεζά/κεφαλαία και προσάρτηση.

## ModuleNotFoundError: flask

**Γλώσσα / περιβάλλον:** DedSec

### Τι σημαίνει
Η Flask λείπει από την Python που εκτέλεσε το DedSec.

### Πώς διορθώνεται
Χρησιμοποίησε το .venv του DedSec ή Python Termux και έλεγξε την εισαγωγή Flask.

## No module named flask_socketio

**Γλώσσα / περιβάλλον:** DedSec

### Τι σημαίνει
Το πακέτο Flask-SocketIO λείπει από το επιλεγμένο περιβάλλον.

### Πώς διορθώνεται
Εκτέλεσε την κατάλληλη εγκατάσταση και δοκίμασε import στο ίδιο περιβάλλον.

## Επαναλήψιμη διάγνωση Python packages

Εκτέλεσε το προβληματικό πρόγραμμα και τον έλεγχο με ακριβώς την ίδια Python. Κατάγραψε `sys.executable`, `sys.version` και `Path.cwd()` και βρες σε ποιο περιβάλλον εγκαταστάθηκε το απαιτούμενο package. Αν λείπει το `flask` ή το `flask_socketio`, σύγκρινε το αποτέλεσμα της εντολής `python -m pip` για τον συγκεκριμένο interpreter, όχι για μια τυχαία Python του συστήματος. Μία εγκατάσταση σε διαφορετικό virtual environment δεν διορθώνει το import.

~~~python
from pathlib import Path
import sys
print(sys.executable)
print(Path.cwd())
print((Path.cwd() / "config.json").resolve())
~~~

Ένα σχετικό όνομα αρχείου εξαρτάται από τον τρέχοντα φάκελο, που μπορεί να διαφέρει από τον φάκελο του script. Δοκίμασε από δεύτερο directory και χρησιμοποίησε ρητά κατάλληλη βάση για τα αρχεία της εφαρμογής. Για το `flask_socketio`, το όνομα που εισάγεις στην Python δεν είναι αναγκαστικά ίδιο με το όνομα του πακέτου διανομής· έλεγξε metadata πριν αλλάξεις imports. Κράτησε την πραγματική εξαίρεση αντί να υποθέσεις ότι λείπουν permissions.
