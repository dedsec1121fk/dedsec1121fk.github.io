# Termux:API unavailable: διαχωρισμός app και plugin

## Αναγνώριση της πραγματικής αποτυχίας
Οι εντολές Termux:API χρειάζονται συμβατή Android εφαρμογή Termux:API και CLI package termux-api. Μία Python βιβλιοθήκη με παρόμοιο όνομα δεν είναι ισοδύναμη. Missing command, denied permission και unsupported Android feature είναι διαφορετικές περιπτώσεις.

## Ασφαλής αρχικός έλεγχος
~~~sh
command -v termux-battery-status
pkg show termux-api
termux-info
~~~

## Διόρθωση αιτίας χωρίς παράκαμψη προειδοποίησης
Έλεγξε συμβατότητα εγκατάστασης, Android permissions και battery/background restrictions. Δοκίμασε read-only battery status πριν ζητήσεις location, contacts ή SMS. Μην παρακάμπτεις άρνηση δικαιώματος· η λειτουργία πρέπει να παραμένει προαιρετική.

**Τεκμηρίωση:** https://github.com/termux/termux-api

## Γιατί απαιτούνται δύο διαφορετικά στοιχεία
Το πακέτο `termux-api` προσθέτει εντολές μέσα στο Termux, ενώ η ξεχωριστή εφαρμογή Android **Termux:API** υλοποιεί την επικοινωνία με τις υπηρεσίες του τηλεφώνου. Αν λείπει το executable είναι σφάλμα εγκατάστασης στο terminal· αν υπάρχει αλλά δεν επικοινωνεί με το Android add-on, πρόκειται για διαφορετικό πρόβλημα.

## Έλεγχος με ακίνδυνα δεδομένα
~~~sh
command -v termux-battery-status
termux-battery-status
~~~
Αν η πρώτη γραμμή δεν επιστρέψει μονοπάτι, επιβεβαίωσε την εγκατάσταση της εντολής μέσω του επίσημου πακέτου Termux. Αν η δεύτερη επιστρέφει πρόβλημα σύνδεσης, έλεγξε την εγκατάσταση της εφαρμογής Termux:API, την προέλευσή της και τη συμβατότητα υπογραφής με το κύριο Termux. Τα αντίστοιχα Android permissions μπορούν να περιορίζουν συγκεκριμένες λειτουργίες.

## Διάκριση αποτυχιών
**Δεν υπάρχει εντολή:** φταίει το shell package ή το PATH. **Υπάρχει εντολή αλλά αποτυγχάνει η επικοινωνία:** έλεγξε το Android add-on και πιθανή ασυμβατότητα εγκαταστάσεων. **Μόνο μία API λειτουργία αποτυγχάνει:** εξέτασε τη σχετική άδεια και τους περιορισμούς της έκδοσης Android. Δεν χρειάζεται να δοκιμάζεις SMS, επαφές, μικρόφωνο ή τοποθεσία για να δεις αν λειτουργεί το add-on: το battery status είναι καταλληλότερο αρχικό διαγνωστικό.

## Τι να αποφύγεις
Μην κατεβάζεις APK από άγνωστες πηγές, μην ενεργοποιείς όλες τις άδειες μαζικά και μην θεωρείς ότι κάθε έκδοση Android παρέχει τις ίδιες δυνατότητες. Κράτα την ακριβή έξοδο του battery command και εντόπισε σε ποιο στάδιο αποτυγχάνει.
