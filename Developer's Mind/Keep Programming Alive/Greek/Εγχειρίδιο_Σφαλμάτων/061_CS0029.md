# CS0029 — Δεν επιτρέπεται αυτόματη μετατροπή τύπων

**Περιβάλλον:** στατικός έλεγχος τύπων στη C#.

## Κατανόηση του σφάλματος
Το CS0029 εμφανίζεται όταν ο τύπος μιας έκφρασης δεν μπορεί να ανατεθεί αυτόματα στον τύπο προορισμού. Η C# δεν μετατρέπει μια συμβολοσειρά σε `int` επειδή περιέχει ψηφία. Άλλες μετατροπές απαγορεύονται επειδή ενδέχεται να χαθεί εύρος ή ακρίβεια. Η λύση εξαρτάται από το τι σημαίνουν τα δεδομένα.

## Αναπαραγωγή και σωστή αντιμετώπιση
~~~csharp
// int quantity = "42"; // CS0029: string προς int
~~~
Χειρίσου την είσοδο ως κείμενο και κάνε ασφαλή μετατροπή:
~~~csharp
using System;
string input = "42";
if (!int.TryParse(input, out int quantity)) {
    Console.Error.WriteLine("Not a valid whole number");
    return;
}
Console.WriteLine(quantity + 1);
~~~
**Αναμενόμενη έξοδος:** `43`, σε σύγχρονο project με top-level statements. Με `"42x"` πρέπει να εκτελεστεί ο κλάδος ελέγχου αντί να προκύψει ανεξέλεγκτο exception.

## Άλλο θέμα: αριθμητικοί τύποι
Η εντολή `int small = 3000000000L;` δεν μεταγλωττίζεται, επειδή ο αριθμός δεν χωρά σε `int`. Ένα explicit cast μπορεί να χάσει πληροφορία ή να αποτύχει σε `checked` context. Αν το πραγματικό πεδίο δεδομένων απαιτεί μεγάλες τιμές, διατήρησε `long`. Για nullable τιμές, καθόρισε τι σημαίνει `null` πριν κάνεις unwrap.

## Οδηγός διόρθωσης
1. Εντόπισε τον πραγματικό τύπο της έκφρασης και του προορισμού.
2. Αποφάσισε αν απαιτείται parsing, ελεγμένο cast, αλλαγή τύπου ή αντιστοίχιση δεδομένων.
3. Δοκίμασε έγκυρες, κενές, μη αριθμητικές και εκτός εύρους τιμές.
4. Μην αποκρύπτεις κάθε αποτυχία εισόδου αντικαθιστώντας τη με μηδέν.
5. Επανέλαβε το build και πρόσθεσε δοκιμή για το αρχικό περιστατικό.

Το `(int)"42"` **δεν** είναι επιτρεπτό cast από string σε int. Η σωστή λειτουργία για κείμενο είναι το parsing.
