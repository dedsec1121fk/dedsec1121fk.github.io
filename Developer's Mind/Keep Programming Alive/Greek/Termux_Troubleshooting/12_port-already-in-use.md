# Θύρα ήδη δεσμευμένη: εντόπισε τον listener με ασφάλεια

## Αιτία και συμπτώματα
Το EADDRINUSE σημαίνει ότι η συγκεκριμένη διεύθυνση/θύρα δεν μπορεί να δεσμευτεί με τις τρέχουσες ρυθμίσεις. Ίσως έχει μείνει δεύτερο αντίγραφο dev server, ή το IPv4 wildcard bind έχει ήδη δεσμεύσει την απαιτούμενη θύρα. Μια τυχαία υψηλή θύρα αποφεύγει συγκρούσεις αλλά δεν εντοπίζει τον κάτοχο μιας συγκεκριμένης θύρας.

## Αναπαραγωγή / διαγνωστικές εντολές
Εκτέλεσε σε δικό σου δοκιμαστικό περιβάλλον και έλεγξε τις διαδρομές πριν αλλάξεις αρχεία.
~~~sh
# In Termux/Linux, inspect listeners where supported:
ss -ltn
# Optionally:
# lsof -nP -iTCP -sTCP:LISTEN
# For a server you started yourself, stop it with Ctrl+C.
# Never run kill -9 on an unknown PID just because its port matches.
~~~

## Επίλυση με βάση τα στοιχεία
Δες διεύθυνση, θύρα και εντολή έναρξης του process. Επιβεβαίωσε αν ο υπάρχων listener είναι αναμενόμενος και ποιος τον κατέχει πριν στείλεις signal. Σταμάτα μόνο γνωστό δικό σου test process ή άλλαξε τη θύρα της εφαρμογής. Το SO_REUSEADDR δεν επιτρέπει γενικά δύο άσχετους ενεργούς listeners στο ίδιο endpoint. Έλεγξε χωριστά IPv4/IPv6.

## Πρακτικό εργαστήριο
Ξεκίνα τοπικό Python HTTP server στη θύρα 8765, δοκίμασε δεύτερο στην ίδια θύρα και σημείωσε το σφάλμα. Σταμάτα μόνο τον γνωστό πρώτο server και επιβεβαίωσε ότι ξεκινά ο δεύτερος. Επανάλαβε με τυχαία θύρα του OS για να εξηγήσεις γιατί τα tests αποφεύγουν fixed ports.
