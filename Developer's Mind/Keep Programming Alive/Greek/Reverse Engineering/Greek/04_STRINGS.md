# Συμβολοσειρές σε binaries: πλαίσιο και όχι απλώς εκτυπώσιμοι χαρακτήρες

## Μοντέλο και όρια συμπερασμάτων
Ακολουθίες εκτυπώσιμων bytes ίσως περιέχουν ετικέτες ή μηνύματα, αλλά μπορεί να είναι τυχαίο δυαδικό περιεχόμενο. Τα UTF-8, UTF-16LE και συμπιεσμένα δεδομένα χρειάζονται διαφορετική ανάλυση. Ένα string hit αποδεικνύει παρουσία bytes, όχι ότι εκτελείται μια λειτουργία ή χρησιμοποιείται κάποια διεύθυνση.

## Αυτοτελές δοκιμαστικό δείγμα
~~~python
import re
raw = b"\x00OK\x00" + "Πείραμα".encode("utf-8") + b"\x00BUILD=dev\x00"
ascii_hits = [(m.start(), m.group().decode("ascii"))
              for m in re.finditer(rb"[\x20-\x7e]{4,}", raw)]
assert any(text == "BUILD=dev" for _, text in ascii_hits)
assert not any("Πείραμα" in text for _, text in ascii_hits)
print(ascii_hits)
# Read UTF-8 segments separately; don't decode arbitrary bytes with 'ignore'.
~~~

## Βήματα έρευνας και ελέγχου
Κατέγραψε byte offsets για κάθε αποτέλεσμα και εξέτασε γειτονικά bytes για συσχέτιση με δομές. Σημείωσε το minimum length εργαλείων όπως strings. Επιβεβαίωσε encoding πριν την αποκωδικοποίηση· το errors='ignore' μπορεί να εξαφανίσει στοιχεία. Μην δημοσιεύεις προσωπικά αναγνωριστικά ή πραγματικά credentials.

## Πρακτικό εργαστήριο
Δημιούργησε δείγμα με ASCII, UTF-8 και UTF-16LE της ίδιας ετικέτας. Γράψε χωριστούς decoders και σύγκρινε αποτελέσματα. Πρόσθεσε τυχαία bytes και δείξε γιατί τα printable hits απαιτούν έλεγχο συμφραζομένων.

## Ίδιο ορατό κείμενο, διαφορετικά bytes
~~~python
label = "Δοκιμή"
assert label.encode("utf-8").decode("utf-8") == label
assert label.encode("utf-16le").decode("utf-16le") == label
~~~
Δημιούργησε δύο ακίνδυνα αρχεία: το πρώτο με UTF-8 και πρόθεμα μήκους, το δεύτερο με UTF-16LE. Ψάξε τα ίδια ελληνικά γράμματα στις ακατέργαστες ακολουθίες και εξήγησε γιατί μια απλή ASCII αναζήτηση δεν τα βρίσκει. Ένα τυχαίο byte run μπορεί να μοιάζει με εκτυπώσιμο κείμενο: επαλήθευσε τη θέση μέσα στο format, το όριο πεδίου και τη σωστή κωδικοποίηση. Χρησιμοποίησε μόνο δικά σου ή εξουσιοδοτημένα δείγματα, όχι εξαγωγή προσωπικών δεδομένων από ξένες εφαρμογές.
## Ευρήματα συμβολοσειρών με όρια και πλαίσιο

Μια ASCII λέξη σε δυαδικό blob δεν αποδεικνύει χρήση ως εντολή, host ή διαπιστευτήριο. Μπορεί να είναι δεδομένα debugging, σύμπτωση ή ανενεργό μήνυμα βιβλιοθήκης. Κράτησε θέση byte και γειτονική δομή πριν αποδώσεις νόημα.

Διάλεξε σκόπιμα κωδικοποίηση εξαγωγής. Οι ακολουθίες ASCII χάνουν UTF-16 με ενδιάμεσα μηδενικά. Ανεκτικός decoder μπορεί να κατασκευάσει αναγνώσιμα τμήματα από άκυρα δεδομένα. Η άσκηση δείχνει δύο κωδικοποιήσεις ίδιου δείκτη με ρητή αποκωδικοποίηση αντί ισχυρισμού πλήρους ASCII σάρωσης.

```python
marker="LAB_NOTE"
blob=b"\x00\xff"+marker.encode("ascii")+b"\x00"+marker.encode("utf-16le")
ascii_offset=blob.index(marker.encode("ascii"))
wide_offset=blob.index(marker.encode("utf-16le"))
assert ascii_offset == 2 and wide_offset > ascii_offset
assert blob[wide_offset:].decode("utf-16le") == marker
print({"ascii_offset":ascii_offset,"utf16_offset":wide_offset})
```

Σύνδεσε υποψήφια συμβολοσειρά με αναφορά ή συμβάν εκτέλεσης πριν θεωρηθεί προσβάσιμη συμπεριφορά. Κράτησε bytes για αναπαραγωγή. Μη δημοσιεύεις πιθανό μυστικό για εντύπωση· απόκρυψε και τεκμηρίωσε τον χειρισμό.
