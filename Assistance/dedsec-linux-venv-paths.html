DedSec Linux venv & Paths

Quick Summary

Understand the Linux environment and file locations DedSec uses so you can troubleshoot without editing the wrong folders.

Project Environment

Desktop Linux uses a local .venv inside the DedSec repository. Run ./Run.sh instead of manually mixing global Python packages with the project.

Check The Environment

cd ~/DedSec
pwd
./.venv/bin/python --version
printf "%s\n" "$PATH"

Compatibility Layer

Compat/bin provides desktop-safe replacements or shims for commands expected by portable scripts. Run.sh adds it automatically.

Downloads

Portable tools normally save under ~/Downloads/ on Ubuntu, Kali Linux, and Linux Mint. Exact per-tool paths are listed on the Learn About The Tools page.

Shell Files

Ubuntu and Linux Mint commonly use ~/.bashrc. Kali may use ~/.zshrc. Termux uses $PREFIX/etc/bash.bashrc.

Next Steps

For platform-specific save paths, use Learn About The Tools. For other setup or runtime problems, return to Assistance.
