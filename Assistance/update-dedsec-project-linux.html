Quick Summary

Update a Linux checkout without replacing the repository or bypassing the cross-platform dependency refresh.

Check The Working Tree

cd ~/DedSec
git status

Review local modifications before pulling so you do not overwrite work you meant to keep.

Pull And Refresh

git pull
bash Setup.sh --update-only
./Run.sh

Why Setup Runs Again

Setup.sh --update-only refreshes dependencies and compatibility files after project updates. The normal launcher then uses the updated .venv and Compat/bin.

Custom Clone Path

If the project is not in ~/DedSec, change into its actual directory first.

Next Steps

For platform-specific save paths, use Learn About The Tools. For other setup or runtime problems, return to Assistance.
