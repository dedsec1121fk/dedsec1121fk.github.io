Repair DedSec Linux Setup

Repair the desktop environment without deleting the whole project or touching unrelated system Python packages.

Assistance›Repair DedSec Linux Setup

Quick Summary

Repair the desktop environment without deleting the whole project or touching unrelated system Python packages.

Check Required Packages

sudo apt update
sudo apt install -y git python3 python3-venv python3-pip

Rebuild Only The Project Environment

cd ~/DedSec
rm -rf .venv
bash Setup.sh --update-only
./Run.sh

The rm -rf command above targets only the DedSec project's local .venv. Confirm you are inside the DedSec directory first.

If Your Clone Is Elsewhere

Use the actual clone path instead of ~/DedSec. Run pwd and git status before changing files.

Android-Specific Tools

Do not try to repair Termux-only utilities as Linux services. Android App Launcher, Mobile Desktop, Termux Backup/Restore, Termux Repair Wizard, and Mobile Developer Setup are intentionally not applicable on desktop Linux.

Next Steps

For platform-specific save paths, use Learn About The Tools. For other setup or runtime problems, return to Assistance.
