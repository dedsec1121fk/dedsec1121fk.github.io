Γρήγορη Περίληψη

Εγκατάστησε το DedSec σε Ubuntu, Kali Linux ή Linux Mint χρησιμοποιώντας τον κοινό cross-platform installer και launcher.

Απαιτήσεις

Χρησιμοποίησε λογαριασμό με sudo access και ενεργή σύνδεση internet. Το DedSec υποστηρίζει Ubuntu, Kali Linux και Linux Mint με το ίδιο desktop setup.

Εγκατάσταση Git

sudo apt update
sudo apt install -y git

Clone Και Setup

git clone https://github.com/dedsec1121fk/DedSec
cd DedSec
bash Setup.sh

Το setup εγκαθιστά desktop dependencies, δημιουργεί .venv και ετοιμάζει το Compat/bin.

Εκκίνηση

./Run.sh

Χρησιμοποίησε αυτόν τον launcher για κανονικές desktop εκτελέσεις ώστε να εφαρμόζονται το local environment και το compatibility layer.

Paths

Η Python του project βρίσκεται στο DedSec/.venv/. Τα compatibility commands στο DedSec/Compat/bin/. Τα outputs των εργαλείων συνήθως χρησιμοποιούν ~/Downloads/ ή το XDG Downloads directory του χρήστη.
